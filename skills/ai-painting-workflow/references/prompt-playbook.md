# 提示词优化手册

## 六要素公式

```
主体（是什么）+ 风格（什么画风）+ 光线氛围 + 构图视角 + 细节锚点 + 质量词
```

| 要素 | 作用 | 示例 |
|---|---|---|
| 主体 | 画面核心对象，写清数量、形态、姿态 | "一只Q版小龙虾，圆润大眼睛" |
| 风格 | 决定整体画风 | "赛博朋克风格，霓虹蓝紫色调" |
| 光线氛围 | 决定情绪与质感 | "城市夜景，霓虹发光，高对比度" |
| 构图视角 | 决定呈现方式 | "居中构图，正面视角" |
| 细节锚点 | 防止模型偷懒的具象细节 | "机械义肢、铆钉装甲、能量核心" |
| 质量词 | 收尾兜底 | "高清细节，潮流插画" |

## 扩写纪律

1. 保留用户原意，只补全不改写；用户的风格词原样保留。
2. 用户说"更酷/更可爱/更专业"这类模糊方向词时，翻译成具象要素：更酷 → 硬朗线条、暗色调、战损纹理、强对比光；更可爱 → Q版比例、大眼睛、圆润轮廓、柔和光。
3. 每轮展示"原话 → 优化后"对照，让用户能直接复用提示词。

## 三场景预设模板

### 1. 教程配图（用于文章、课件、操作指引）

```
[主体内容]，信息图表风格/扁平插画风格，简洁背景（浅灰或纯白），
清晰的视觉层级，主体居中偏上，留出标注空间，
配色不超过4种主色，线条干净，无杂物，
高质量矢量感插画
```

要点：尺寸默认 1536x1024（横版，适配文档宽度）；背景必须干净，避免喧宾夺主。

### 2. 白板总结图（手绘风知识卡片、脑图感）

```
[知识主题]，手绘白板风格，白底黑字马克笔笔触，
重点词用彩色高亮（红/蓝/黄），带简单箭头和框线连接，
略带倾斜的手写体感觉，卡通小图标点缀，
俯视视角，像真实白板照片
```

要点：文字内容由模型生成，可靠性有限——多文字白板图建议先生成底图再由用户后期加字，或控制文字量在 10 个词以内。

### 3. 社媒配图（公众号头图、小红书、朋友圈）

```
[主题内容]，潮流插画/3D渲染风格，饱和度适中的时尚配色，
主体突出占画面约60%，背景简洁有氛围，
竖版选 1024x1536，横版头图选 1536x1024，
细节丰富，视觉冲击力强，适合移动端浏览
```

要点：平台适配——公众号头图 1536x1024；小红书 1024x1536；朋友圈/配图 1024x1024。

## 批量参数说明

批量清单 CSV 列定义（模板见 `assets/batch-template.csv`）：

| 列 | 必填 | 说明 | 默认 |
|---|---|---|---|
| id | 否 | 任务编号，缺省自动生成 001/002... | 自动 |
| prompt | 是 | 提示词（可只写主体+风格，执行前按六要素补全） | — |
| size | 否 | 尺寸 | 取配置 default_size |
| quality | 否 | low/medium/high | 取配置 default_quality |
| style | 否 | 风格参数 | 取配置 default_style |
| ref_image | 否 | 参考图路径，有值则该条走图生图 | 空（文生图） |

批量纪律：执行前必须展示计划与总积分预估并获确认；失败条目记录原因继续批次，最后汇总。
