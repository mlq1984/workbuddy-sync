## 关键参数说明

### size + ratio 组合使用（推荐）
```json
{
  "size": "2K",
  "ratio": "9:16"
}
```
→ 服务端按原生档位输出 **1472×2624**，无插值失真。

### 精确尺寸写法（兼容但不推荐）
```json
{
  "size": "1472x2624"
}
```
→ 服务端会自动映射到最接近的标准档位，可能产生微小尺寸差异。
