# 技术面综合评分体系

总分 100 分，五个维度。评分结果用于量化技术面强弱程度，辅助决策。

---

## 评分维度与权重

### 1. 趋势分（25分）

| 评估项 | 满分 | 评分标准 |
|--------|------|----------|
| 趋势方向清晰度 | 10 | 方向明确（多头/空头排列清晰）= 10；方向模糊/均线纠缠 = 5；无趋势 = 0 |
| 趋势强度 | 8 | 均线斜率陡峭 + 连续性强 = 8；斜率中等 = 5；平缓 = 2 |
| 多周期共振 | 7 | 长中短期同向 = 7；两周期同向 = 4；方向不一致 = 1 |

### 2. 量价分（20分）

| 评估项 | 满分 | 评分标准 |
|--------|------|----------|
| 量价配合健康度 | 12 | 量价齐升 = 12；缩量上涨 = 7；放量滞涨 = 4；放量下跌 = 0 |
| 成交量异常 | 4 | 无异常 = 4；轻微异常 = 2；严重异常（天量天价/地量地价）= 0 |
| 换手率合理性 | 4 | 正常水平(1-7%) = 4；过高或过低 = 2；极端 = 0 |

### 3. 指标分（20分）

| 评估项 | 满分 | 评分标准 |
|--------|------|----------|
| 指标共振程度 | 12 | 3+指标同向 = 12；2指标同向 = 8；1指标 = 4；全部矛盾 = 0 |
| 指标位置合理性 | 8 | 健康区间（非极端超买超卖）= 8；接近极端 = 4；极端超买超卖 = 0 |

**指标背离扣分：**
- 顶背离：量价分和指标分各扣 5 分
- 底背离：量价分和指标分各加 3 分（加分后不超过满分）

### 4. 形态分（15分）

| 评估项 | 满分 | 评分标准 |
|--------|------|----------|
| 形态完整性 | 8 | 形态已确认完成 = 8；形态形成中 = 4；无明确形态 = 2 |
| 形态信号强度 | 7 | 强反转/中继形态 = 7；普通形态 = 4；弱信号 = 2 |

### 5. 资金分（20分）

| 评估项 | 满分 | 评分标准 |
|--------|------|----------|
| 主力资金流向 | 10 | 持续净流入 = 10；小幅净流入 = 7；持平 = 5；净流出 = 2；大幅流出 = 0 |
| 筹码结构 | 5 | 筹码集中 + 获利盘多 = 5；一般 = 3；套牢盘多 = 1 |
| 北向/融资 | 5 | 持续买入 = 5；持平 = 3；持续卖出 = 0（无数据则此项不计，总分按比例折算）|

---

## 评分等级

| 分数区间 | 等级 | 技术面状态 | 操作倾向 |
|----------|------|------------|----------|
| 90-100 | 极强 | 多维共振偏多 | 可重仓做多 |
| 80-89 | 强 | 偏多信号明确 | 可中等仓位做多 |
| 70-79 | 良好 | 偏多但需确认 | 轻仓试多 |
| 60-69 | 一般 | 中性偏多 | 小仓位或观望 |
| 50-59 | 中性 | 震荡格局 | 观望为主 |
| 40-49 | 偏弱 | 中性偏空 | 谨慎，不宜做多 |
| 30-39 | 较弱 | 偏空信号出现 | 考虑减仓/回避 |
| 20-29 | 弱 | 偏空信号明确 | 不宜持有 |
| 0-19 | 极弱 | 多维共振偏空 | 坚决回避 |

---

## 评分计算示例

假设某股分析结果：
- 趋势分：方向清晰(8) + 强度中等(5) + 两周期共振(4) = 17/25
- 量价分：量价齐升(12) + 无异常(4) + 正常(3) = 19/20
- 指标分：2指标同向(8) + 健康区间(6) = 14/20
- 形态分：形态形成中(4) + 普通形态(4) = 8/15
- 资金分：持续净流入(10) + 一般(3) + 持续买入(4) = 17/20

**总分 = 17 + 19 + 14 + 8 + 17 = 75 分**

**等级：良好 — 偏多但需确认，可轻仓试多**

---

## 注意事项

1. 评分是辅助工具，不是交易系统。最终决策需结合共振判断和风控要求。
2. 评分中未考虑基本面和消息面，纯技术面评估有局限性。
3. 不同市场阶段评分的有效性不同 — 趋势市中评分更可靠，震荡市中评分波动大。
4. 评分应定期更新（至少每日盘后），技术面状态会随行情变化而改变。
