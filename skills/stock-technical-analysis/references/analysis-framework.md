本文件展开六层递进分析的完整方法论。每层结论约束后层分析，不可跳层。

## 数据获取（选股魔方 REST API 映射）

所有行情数据通过 `scripts/call_tool.py` 调用选股魔方 REST Skill API 获取，不依赖 MCP。调用约定与退出码处理见 SKILL.md「数据获取」章节，工具白名单见 `tools.md`。

各层数据来源速查：

| 层 | 需要的数据 | REST 工具 | 备注 |
|----|-----------|-----------|------|
| L1 基本信息 | 代码/名称/价格/涨跌幅/市值/板块 | `lookup_sec_id` + `snapshot` + `company_f10`(COMP_DETAIL, SW_INDUSTRY) | 先 `lookup_sec_id` 得到标准 `sec_id` |
| L2 多周期趋势 | 周K≥52根、月K≥24根、日K（近30日，`trend` 分时聚合） | `kline_range`（period: week/month）+ `trend`（days≤30） | ⚠️ REST K线接口不支持 `day` 周期（实测 `period=day` 报参数异常，仅 week/month/season/year 可用）；日K用分时聚合，更早日K历史标注"数据不可用" |
| L3 关键价位 | K线高低点、缺口、均线位置 | `kline_range`(week/month) + `trend`聚合日K + 自行计算 | 筹码密集区若 REST 不可用则标注"数据不可用" |
| L4 五维验证 | 量/价/换手、指标、资金 | `kline_range` + `trend` + `snapshot` + `market_signal` + `company_f10`(MARGIN_TRADE/STRANGE_TRADE) | 主力净流入不可用 → 用融资融券/龙虎榜/`ddx`/量价替代并注明 |
| L5 评分 | 上述全部 | 汇总 | 缺失维度该维度记低分并在报告中披露 |
| L6 风控 | 关键价位 | 汇总 | 止损/仓位基于上述分析 |

示例命令：

```bash
# 1. 名称转代码
python scripts/call_tool.py --tool lookup_sec_id --arguments '{"keyword":"贵州茅台"}'
# 2. 行情快照
python scripts/call_tool.py --tool snapshot --arguments '{"sec_id":"600519.SH"}'
# 3. 周K线（52根以上，日期用 yyyyMMdd；period 仅支持 week/month/season/year，不支持 day）
python scripts/call_tool.py --tool kline_range --arguments '{"sec_id":"600519.SH","period":"week","start":"20240101","end":"20260821"}'
# 4. 日K线（近30日，由分时数据按日聚合：open=首根、high/low=max_high_price/min_low_price、close=末根；volume/value 为当日累计值，取每日末行即全天总量，勿对全行 sum）
python scripts/call_tool.py --tool trend --arguments '{"sec_id":"600519.SH","days":30}'
# 4b. 股本结构（总市值=现价×total_ashr、流通市值=现价×float_ashr）
python scripts/call_tool.py --tool company_f10 --arguments '{"datasets":["CAP_LATEST"],"sec_id":"600519.SH"}'
# 5. 公司资料+行业
python scripts/call_tool.py --tool company_f10 --arguments '{"datasets":["COMP_DETAIL","SW_INDUSTRY"],"sec_id":"600519.SH"}'
# 6. 融资融券
python scripts/call_tool.py --tool company_f10 --arguments '{"datasets":["MARGIN_TRADE"],"sec_id":"600519.SH"}'
# 7. 龙虎榜（先日期列表，再明细）
python scripts/call_tool.py --tool company_f10 --arguments '{"datasets":["STRANGE_TRADE_DT"],"sec_id":"600519.SH"}'
```

退出码 `10` 表示需要微信扫码授权：把 stdout 中 `qrMarkdown:` 后的 Markdown 图片原样放入回复，用户扫码后重新发送原请求。

## 第一层：个股基本信息

获取并展示：
- 股票代码、名称
- 当前价格、涨跌幅、涨跌额
- 总市值、流通市值
- 所属板块/概念
- 最近交易日

此层目标：明确分析标的，快速建立基本面印象。大市值与小市值的技术特征不同（大市值趋势更稳定，小市值波动更剧烈）。

## 第二层：多周期趋势嵌套

核心原则：**高级别约束低级别。** 这是技术分析中最有实战价值的思维模型。

### 长期趋势（周线/月线）

分析要素：
- **均线排列**：MA5/10/20 周线 — 多头排列（5>10>20 且价格在上方）= 上升趋势
- **高低点结构**：高点逐步抬高 + 低点逐步抬高 = 上升趋势；反之 = 下降趋势
- **趋势线**：连接两个以上低点画上升趋势线（或高点画下降趋势线），验证有效性
- **价格与 MA20 周线关系**：站上方 = 中长期偏多；在下方 = 中长期偏空

判断结论：长期趋势方向（上升/下降/震荡）+ 趋势强度（强/中/弱）

### 中期趋势（日线）

分析要素：
- **均线系统**：MA5/10/20/60 日线 — 关注排列方向及粘合/发散状态
  - 多头排列（5>10>20>60）= 中期偏多
  - 空头排列（5<10<20<60）= 中期偏空
  - 均线粘合 = 方向选择临界点
- **价格与 MA60 关系**：MA60 是中期牛熊分界线的重要参考
- **中期趋势线**：日线级别的趋势线验证
- **回调/反弹结构**：上升趋势中的回调幅度、下降趋势中的反弹幅度

判断结论：中期趋势方向 + 关键均线支撑/压力位

### 短期趋势（60分钟/30分钟）

分析要素：
- **短周期均线**：MA5/10/20（60分钟级别）
- **短期动能**：最近几根K线的实体方向和大小
- **短期买卖点**：均线金叉/死叉、K线反转信号
- **短期支撑/压力**：60分钟级别的密集成交区

判断结论：短期动能方向 + 短期买卖点信号

### 多周期共振判断

| 周线 | 日线 | 60分钟 | 判断 | 操作倾向 |
|------|------|--------|------|----------|
| 上升 | 上升 | 上升 | 强共振偏多 | 寻找买点 |
| 上升 | 回调 | 回调 | 周线约束下的回调 | 等日线企稳找买点 |
| 上升 | 下降 | 下降 | 趋势可能转弱 | 观望或轻仓 |
| 下降 | 下降 | 下降 | 强共振偏空 | 回避或找卖点 |
| 下降 | 反弹 | 反弹 | 周线约束下的反弹 | 反弹找卖点 |
| 震荡 | 震荡 | 震荡 | 无趋势 | 区间操作或观望 |

**关键提醒**：只看一个周期就下结论是最常见的错误。周线还在空头排列，在日线上看到金叉就冲进去，大概率被套。

## 第三层：关键价位定位

### 支撑位识别（由强到弱）

1. **前期低点**：最近1-3个月的 swing low
2. **均线支撑**：MA20/MA60/MA120/MA250 — 越长期的均线支撑越强
3. **跳空缺口下沿**：突破缺口/中继缺口有支撑意义
4. **筹码密集区下沿**：前期长时间盘整区间
5. **黄金分割位**：0.382 / 0.5 / 0.618（基于最近一轮显著波段的高低点计算）
6. **整数关口**：如10元、50元、100元等心理价位

### 阻力位识别（由强到弱）

1. **前期高点**：最近1-3个月的 swing high
2. **均线压力**：上方均线构成反弹阻力
3. **跳空缺口上沿**：衰竭缺口上沿有压力意义
4. **筹码密集区上沿**：套牢盘集中区域
5. **黄金分割位**：1.382 / 1.5 / 1.618
6. **整数关口**

### Pivot 位（中线平衡位）

- 当前价格距上方最近阻力位 X%
- 当前价格距下方最近支撑位 Y%
- 若 X < Y → 偏向阻力，上行空间有限
- 若 X > Y → 偏向支撑，下行空间有限

### 输出格式

```
关键价位：
- 强支撑：XX 元（距当前价 -X%）
- 支撑：XX 元（距当前价 -X%）
- 当前价：XX 元
- 阻力：XX 元（距当前价 +X%）
- 强阻力：XX 元（距当前价 +X%）
```

## 第四层：五维交叉验证

### 维度一：趋势（25分）

**判断标准：**
- 方向：上升 / 下降 / 震荡
- 强度：均线斜率陡峭 = 强趋势；平缓 = 弱趋势
- 稳定性：回调幅度小、均线不交叉 = 稳定；频繁交叉 = 不稳定
- 多周期共振度：长中短期方向一致 = 高共振

**趋势强弱的快速判断法：**
- 价格站上所有短中期均线（5/10/20/60）= 强多头
- 价格在 MA20 和 MA60 之间 = 中性
- 价格跌破所有短中期均线 = 强空头

### 维度二：量价（20分）

**量价配合模式：**

| 价格 | 成交量 | 含义 | 信号 |
|------|--------|------|------|
| 上涨 | 放量 | 量价齐升，买盘积极 | 健康看涨 |
| 上涨 | 缩量 | 量价背离，跟风不足 | 警示，可能回落 |
| 下跌 | 缩量 | 缩量回调，抛压减弱 | 正常调整（上升趋势中） |
| 下跌 | 放量 | 放量下跌，恐慌蔓延 | 看跌 |
| 横盘 | 地量 | 无人关注，底部区域 | 可能见底 |
| 横盘 | 天量 | 放量滞涨，主力派发 | 可能见顶 |

**换手率参考标准（A股）：**
- < 1%：极度低迷，关注度低
- 1-3%：正常水平
- 3-7%：活跃，适合短线
- 7-15%：高度活跃，警惕
- > 15%：异常活跃，高位需警惕主力派发

**量价背离是强烈警示信号：** 价格创新高但成交量低于前一波上涨的成交量 = 顶背离，上涨动能不足。

### 维度三：指标（20分）

注意：指标是辅助工具，不作为主要决策依据。

**MACD（指数平滑异同移动平均线）：**
- DIF 上穿 DEA = 金叉（偏多信号）
- DIF 下穿 DEA = 死叉（偏空信号）
- 红柱放大 = 多头动能增强；绿柱放大 = 空头动能增强
- **顶背离**：价格创新高，MACD 未创新高 → 强烈看跌信号
- **底背离**：价格创新低，MACD 未创新低 → 强烈看涨信号
- 零轴上方 = 中期偏多环境；零轴下方 = 中期偏空环境

**KDJ（随机指标）：**
- K > 80 = 超买区；K < 20 = 超卖区
- K 上穿 D = 金叉（偏多）；K 下穿 D = 死叉（偏空）
- J 值 > 100 或 < 0 为极端区域
- 高位死叉比低位金叉信号更可靠

**RSI（相对强弱指标）：**
- RSI > 70 = 超买；RSI < 30 = 超卖
- RSI > 50 = 偏多；RSI < 50 = 偏空
- 顶背离/底背离判断同 MACD

**BOLL（布林线）：**
- 触及上轨 = 短期偏强，可能回调
- 触及下轨 = 短期偏弱，可能反弹
- 布林带开口放大 = 波动率增大，趋势加速
- 布林带收口 = 波动率降低，即将选择方向

**指标共振判断：**
- 3+ 指标同向 = 指标共振，信号可靠
- 指标方向不一致 = 信号冲突，以量价为准

### 维度四：形态（15分）

**反转形态：**
- **头肩顶**：左肩-头-右肩，颈线跌破确认，目标位 = 颈线到头顶的距离
- **头肩底**：镜像结构，颈线突破确认
- **双顶（M顶）**：两次冲高不过前高，跌破颈线确认
- **双底（W底）**：两次探底不破前低，突破颈线确认
- **V型反转**：急跌急涨或急涨急跌，需放量确认

**持续形态：**
- **上升三角形**：水平阻力 + 上升趋势线，突破阻力看涨
- **下降三角形**：水平支撑 + 下降趋势线，跌破支撑看跌
- **对称三角形**：收敛，方向不定，看突破方向
- **旗形/楔形**：短期整理，原趋势延续概率大
- **箱体**：水平震荡，突破方向决定后续趋势

**K线形态（近3-5日）：**
- 看涨：锤子线、早晨之星、看涨吞没、刺穿形态
- 看跌：射击之星、黄昏之星、看跌吞没、乌云盖顶
- 中性：十字星（需结合位置判断）、螺旋桨

**缺口分析：**
- 普通缺口：很快回补，意义不大
- 突破缺口：放量跳空突破，趋势启动信号
- 持续性缺口：趋势中继，测量缺口
- 衰竭缺口：趋势末端，即将反转

### 维度五：资金（20分）

**主力资金流向：**
- 近5日/10日主力资金净流入趋势
- 大单/特大单买卖比例
- 主力净流入 + 价格上涨 = 主力吸筹，健康
- 主力净流出 + 价格上涨 = 主力派发，危险

**筹码分布：**
- 筹码集中度：高度集中 = 主力控盘，趋势可能加速
- 筹码峰位置：获利盘比例高 = 上方抛压小；套牢盘比例高 = 反弹遇阻
- 双峰形态：上峰套牢 + 下峰获利 = 震荡格局

**北向资金（A股）：**
- 北向持续净买入 = 外资看好，中期偏多参考
- 北向持续净卖出 = 外资看空，中期偏空参考

**融资融券（如可用）：**
- 融资余额持续增加 = 杠杆资金看多情绪升温
- 融资余额高位回落 = 杠杆资金开始离场

## 第五层：共振判断与评分

### 共振判断逻辑

1. 分别统计五维的偏多/中性/偏空判断
2. 计算共振度：

| 共振情况 | 置信度 | 操作倾向 |
|----------|--------|----------|
| 4-5维共振偏多 | 高 | 寻找买点 |
| 3维偏多 | 中 | 等待确认 |
| 2-2-1分歧 | 低 | 观望 |
| 3维偏空 | 中 | 谨慎 |
| 4-5维共振偏空 | 高 | 回避/减仓 |

3. **背离检查**：即使共振偏多，若量价维度出现顶背离，置信度降一级

见 `scoring-system.md`。

## 第六层：风控与操作建议

### 止损设置

- 止损位 = 技术关键位的略下方（支撑位下方1-3%）
- 支撑跌破 = 分析逻辑被证伪，必须离场
- 止损位不是随意百分比（如-5%），而是有技术依据的位置
- 止损幅度 = (入场价 - 止损价) / 入场价

### 仓位管理

**金字塔分仓法：**
1. 试仓：总仓位的 30%，在初步信号出现时入场
2. 加仓：信号确认后加 30-40%
3. 最后加仓：突破关键位后加剩余 30%，或不再加仓
4. 减仓：出现警示信号时先减 50%，破止损位清仓

**仓位与评分的关系：**
- 评分 80+：可 60-80% 仓位
- 评分 70-79：可 40-60% 仓位
- 评分 60-69：可 20-40% 仓位
- 评分 50-59：10-20% 或空仓
- 评分 < 50：空仓观望

### 盈亏比评估

- 潜在收益 = 目标价（阻力位/形态目标位） - 入场价
- 潜在风险 = 入场价 - 止损价
- 盈亏比 = 潜在收益 / 潜在风险
- **盈亏比 ≥ 2:1 才值得操作**，低于此值说明风险收益不对等

### 三种策略

| 策略 | 入场时机 | 仓位 | 止损 | 适合场景 |
|------|----------|------|------|----------|
| 激进 | 首个信号出现 | 较大 | 较紧 | 强趋势中顺势操作 |
| 稳健 | 信号确认后 | 中等 | 标准 | 正常市场环境 |
| 保守 | 多重确认后 | 较小 | 较宽 | 震荡市或不确定时 |

### 持仓管理

- 入场后重新评估周期：每日盘后检查趋势是否变化
- 趋势延续 → 持有，可顺势加仓
- 趋势走平 → 减仓至半仓
- 趋势反转 → 清仓离场

## 常见误区

1. **单周期盲区** — 只看日线下结论，忽略周线大方向约束。周线还在空头排列，日线上看到金叉就冲进去，大概率被套。
2. **指标至上** — 把 MACD 金叉当买入信号，忽略量价是否配合。指标是衍生品，量价才是本质。
3. **确认偏误** — 只看支持自己判断的信号，忽视矛盾信号。信号矛盾时应观望，不是选择性失明。
4. **追涨杀跌** — 在价格已远离关键位时才给建议，盈亏比已不合适。好买点在支撑位附近，不在大涨之后。
5. **无止损入场** — 给买入建议但不设止损位。没有止损的交易不是交易，是赌博。
6. **形态万能论** — 认为头肩顶一定会跌。形态有失败概率，需结合量价验证。市场是活的，不是教科书。
7. **忽视位置** — 同样的 K 线形态在高位和低位含义不同。高位的锤子线可能是反转信号，低位的锤子线才是看涨信号。
