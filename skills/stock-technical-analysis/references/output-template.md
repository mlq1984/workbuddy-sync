# 输出模板

## 判断语气规范（强制）

报告中的所有表述分为三层，**必须视觉可区分**：

### 第一层：接口直给数据（事实层）
- 来源：选股魔方 REST API 返回的原始字段值（价格、成交量、涨跌幅、DDX、融资余额等）
- 语气：照实陈述，数字精确到接口返回的小数位
- **禁止**对原始数据加情绪修饰词（如"暴增""暴跌""狂飙"），用"增/减/升/降"即可
- 示例：`融资余额 8.42 亿元（5日增 167.7%）` ✅ ｜ `融资余额暴增 167.7%` ❌

### 第二层：本地计算派生指标（计算层）
- 来源：用接口数据在本地按公式计算的指标（MA/MACD/KDJ/RSI/BOLL/黄金分割/融资变化率等）
- 语气：客观陈述计算结果，注明计算口径
- 在报告中标注 `[计算]` 标签或注明"基于XX数据计算"
- 示例：`MA5=87.84 [计算，近30日口径]`

### 第三层：综合推断定性表述（判断层）
- 来源：基于第一层+第二层综合推理的定性判断（如"疑似派发""射击之星雏形""散户接盘"等）
- **强制使用以下词汇**：或、可能、疑似、建议、参考、暂看、或呈现、或指向
- **禁用以下词汇**：必、将、唯一、确认、无可争议、显然、一定、必然、铁定、目标位看
- 在报告中标注 `[推断]` 标签
- 示例：`疑似伴随派发行为 [推断]` ✅ ｜ `主力派发信号` ❌

### 禁用词清单（全文扫描必过）
| 禁用词 | 替换为 |
|--------|--------|
| 必须 | 建议/可考虑 |
| 将（表预测） | 或/可能 |
| 唯一（正确选择） | 相对稳妥（的选择） |
| 确认（趋势/形态） | 或指向/若形态确立 |
| 无可争议 | （删除，直接陈述） |
| 显然 | （删除或改为"从数据看"） |
| 目标位看XX | 下方可参考XX区域 |
| 将引发 | 可能放大 |
| 将造成 | 可能导致 |
| 暴增/暴跌/狂飙 | 增/跌/升（去情绪化） |
| 明确偏多/明确偏空 | 暂看偏多/偏多（去掉"明确"） |
| 严重超买/严重超跌 | 超买迹象明显/超卖迹象明显 |
| J值拐头（无时间序列依据时） | J值偏低 [推断]（仅当已计算指标时间序列时才可说"拐头"） |

### 核心结论补强规则（强制）

**结论性内容（长期/中期/短期结论、共振判断、综合评分解读、总结框、核心一句话）本身属于第三层判断层，同样必须使用留余地语气**——不能正文软化、结论又变回绝对：

- ✅ `长期方向暂看偏多` ｜ ❌ `长期方向明确偏多`
- ✅ `若回调至67-75区间并企稳，或提供中线买点` ｜ ❌ `回调至67-75区间是较好的中线买点`
- ✅ `短期动能或有所转弱` ｜ ❌ `短期动能转弱`（断言）
- 结论动词一律从"或/可能/暂看/建议/参考"中选，数据描述（涨幅、价格、得分）照实陈述不受限

## 数据准确性自检清单（强制，交付前逐项过）

报告生成后、呈现给用户前，**必须逐项核对以下清单，任何一项不通过先修复再交付**：

### A. 单位与口径
- [ ] **成交量单位为"股"不是"手"**（snapshot/trend/kline 的 volume 字段；1手=100股，写错放大100倍）
- [ ] 成交额单位（元/亿元）与数值量级匹配
- [ ] 市值（tcap/mcap，万元 or 亿元）换算后量级与常识匹配（百亿级公司不可能显示几亿）
- [ ] 表格标签计数与实际数据点数一致（"近3月"就必须是3个点）

### B. 数据溯源
- [ ] 报告中**每个数字**都能指认来源：接口字段 / 本地计算（标`[计算]`） / 综合推断（标`[推断]`，且不出现无来源数字）
- [ ] **open ≠ pre_px**：当日有 snapshot 时，open 必须用 snapshot 真实值；用 pre_px 近似时必须加注说明
- [ ] 分时聚合日K：volume/value 取每日**末行**（当日累计值），不得对全行求和
- [ ] 派生百分比（如融资5日变化率）注明计算口径（首末两点对比）
- [ ] **不可用维度不占行**（强制）：REST API 未提供的字段（北向资金个股流向、筹码分布、超大单/大单分档买卖比例等），表格行**直接删除**，不留"数据不可用 / 未提供 / —"占位。仅在报告末尾"数据说明"区块用一行集中列出未覆盖维度即可

### C. 指标断言验证
- [ ] 只有在**实际计算了指标时间序列**时，才允许写"拐头/金叉/死叉/背离"这类时序性结论；只算了终值时只能写当前值+`[推断]`
- [ ] 近似数据（high/low 为 open/close 包络估算）计算出的指标，必须在数据说明中注明精度局限

### D. 语气终扫
- [ ] 全文 grep 禁用词清单（上表），含"明确/严重/强劲/唯一/必须/确认/暴增"等，逐处替换
- [ ] 总结框与"核心一句话"单独复查一遍（最容易残留绝对语气的地方）

## HTML 输出建议

完整分析报告推荐输出为自包含 HTML（内嵌 CSS + JS），特点：
- 使用 A 股配色惯例：涨红跌绿
- 关键价位用表格展示，一目了然
- 评分用进度条或仪表盘可视化
- 技术指标表格用颜色标注信号方向
- 资金流向用红绿标注
- **表格对齐统一**（强制）：所有单元格统一**左对齐**；`td.num` 仅用于等宽数字字体（`font-variant-numeric: tabular-nums`），**禁止给 num 类加 `text-align: right`**——同一列里部分行右对齐、部分行左对齐会造成左右混排。若需数值列右对齐，则该列**所有行**必须统一加 num 类，二者只能选其一
- 适配深色/浅色主题
- **数据分层标注**：接口直给的数据不加标签；`[计算]` 标注本地派生指标；`[推断]` 标注综合判断

## 数据单位与精度规范

| 字段 | API 返回单位 | 报告显示单位 | 注意事项 |
|------|-------------|-------------|----------|
| volume（成交量） | **股** | 万股 或 万手（÷100） | ⚠️ 1手=100股，API返回的是股数，不是手数。显示"万手"时必须÷100 |
| value（成交额） | 元 | 亿元（÷1e8） | — |
| tcap/mcap/free_mcap | 元 | 亿元（÷1e8） | — |
| turnover_rate | 百分比 | % | 已是百分比，直接显示 |
| ddx | 数值 | — | 大单动向综合值，无单位 |
| main_net_turnover | 元 | 亿元（÷1e8） | — |

### 日K精度说明

- 日K通过 `trend` 分时数据聚合获取（近30日口径）
- **open** = 当日首根分时的 price（非 pre_px/前收），⚠️ pre_px 是前一日收盘，不能当作当日 open
- **close** = 当日末根分时的 price（或下一日 pre_px 回填）
- **high/low** = 当日 `max_high_price` / `min_low_price`（从分时数据提取，非 max(open,close) 近似）
- 如分时数据因输出截断无法获取完整 high/low，**必须在报告中注明"日K high/low 为近似值"**
- KDJ 依赖 9 日 high/low，近似值会导致 KDJ 精度下降，需注明
