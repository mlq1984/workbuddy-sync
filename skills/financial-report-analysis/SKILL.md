# 财报解读分析

## 一、目的

把一家公司的最新财报，先建季度序列、再扫异常、再拆成三个维度，并全程叠加**行业与公司关键经营指标（KPI）**，产出一份**结构化、可归档的 HTML 网页解读报告**。它回答六个问题：

1. 这家公司近几个季度是在变好还是变坏？（先用季度序列定趋势底座）
2. 这份财报里有没有"不对劲"的地方？（用序列背离 + 勾稽/同业背离抓红旗）
3. 这家公司账面上健不健康？（用数据判定，且判定要叠加趋势修正）
4. 这是不是一门好生意、赚的是不是真钱、管理层怎么分钱？（"读生意"视角，巴菲特 / 唐朝 / 段永平框架）
5. 管理层自己说下一步要怎么干？（用一手/二手纪要提炼）
6. **为什么变好 / 变坏？——用量、价、结构、份额、单位经济五元组解释财务数字的成因**（如比亚迪：单车均价、单车净利、高端车占比、出口占比、市占率）

> 设计取舍：本技能专注财报解读与生意判断，**不做估值与买卖点**（交给 `laotang-investment-framework` 或 `wb-finance-skill`）；护城河/竞争力的深度定性可配合 `公司竞争力分析`。
>
> **为什么必须有经营指标**：毛利率下滑 2pct 是"结果"，单车均价下滑 5% 而单车成本只降 2% 才是"原因"。**只做财务比率的解读是不完整的**——它无法回答"下一季会不会继续坏"，也无法给出可验证的跟踪变量。经营指标既是财务结果的解释变量，也是下一季度的验证指标。

## 二、季度明细数据与趋势诊断（分析底座）

核心原则：**单点数据只能说明"现在是好是坏"，季度序列才能说明"在变好还是变坏"。** 财务健康度 = **水平判定**（当期值 vs 阈值）+ **趋势判定**（序列方向 vs 自身轨道）；两者冲突时**以趋势为准**——当期漂亮但连续 3 季恶化的指标，定「关注」而非「健康」。

### 1. 必做动作

- 抓取近 **8 季**定期报告（要 3 年趋势取 12 期）；`westock-mcp` 的 `data_finance` 取数时 **num 多给 4 期**（如输出 8 季则取 12 期），否则最早几期的单季值无法拆算。
- **A 股 / 港股定期报告均为累计口径，必须拆成单季**：单季 = 本期累计 − 上期累计（同一财年内）；毛利率等比率须还原分子分母再相除（不可直接相减）。
- 用 `scripts/quarterly_trend.py` 自动完成拆算、YoY / QoQ、TTM 与趋势特征出表，避免手算错误。
- 详细方法、字段映射表、陷阱清单见 `references/quarterly_trend_analysis.md`。

### 2. 趋势诊断五看（每个核心指标都过一遍）

| 看法 | 做法 | 判定 |
|---|---|---|
| **看方向** | 近 4 季线性回归斜率（年化） | >+5%/年 改善，±5% 平稳，<−5%/年 恶化 |
| **看连续** | 从最近一期往前数同向期数 | **同向连续 ≥3 期 = 趋势确立**（无论当期多漂亮） |
| **看波动** | 变异系数 CV（近 8 季） | <0.15 平稳；0.15~0.30 波动；>0.30 高波动（周期股/项目制属正常，结合行业判断） |
| **看拐点** | 斜率符号是否反转 | 拐点必须追因：景气切换 / 战略调整 / 一次性因素 |
| **看背离** | 指标序列是否分道扬镳 | 见下方四条核心背离对 |

**四条核心背离对（命中即升级关注）**：
- 营收序列 ↑ 但应收周转序列 ↓ → 赊销换收入
- 净利序列 ↑ 但 OCF 序列 ↓ → 纸面利润
- 归母序列 ↑ 但扣非序列走平 → 非经常性撑业绩
- 存货序列 ↑ 但营收序列走平/↓ → 滞销积压前兆（毛利率同步 ↓ 则大概率后续计提减值）

### 3. 三条硬规则（实测校准，违反即出错）

1. **增速字段后缀**：带 `_Q` = 单季口径（`NPParentCompanyYOY_Q`、`TORGrowRate_Q`），不带 = 累计口径（`NPParentCompanyYOY`、`TORGrowRate`）。**拿累计增速当单季增速读，是财报分析最高频的错误。**
2. **禁止跨季度横向比较的指标**：周转率（`ARTRate`/`InventoryTRate`/`TotalAssetTRate`）与 ROE / ROIC 均为**累计期口径**（茅台 Q1 应收周转率 3084 vs 半年 57047；H1 ROE 17.7% vs 全年 33.6%）。只能**同比同期比**（Q1 vs Q1）；跨期比较一律用 TTM（`ROETTM`/`OperatingRevenueTTM`）。
3. **强季节性行业以 YoY 为主口径**：白酒（Q1+Q4 旺）、电商（Q4、Q2 618）、软件 To B（Q4 验收）、教育（Q3 暑期）、地产链（Q4 竣工）。QoQ 须与**去年同期 QoQ** 对照后再解读，不可直接读。脚本会输出「季节性强度」（>0.15 即告警）。

### 4. 趋势对健康度的修正规则

| 情形 | 档位 |
|---|---|
| 水平达标 + 趋势平稳或向上 + CV 低 | **健康** |
| 水平达标 + 连续 2 季同向恶化 | **健康（趋势转弱）**——须点名下行起点与原因 |
| 水平达标 + 连续 ≥3 季同向恶化 | **关注**（趋势优先于水平） |
| 水平未达标 + 趋势向上且连续 ≥2 季改善 | **关注（改善中）**——给改善一个确认期 |
| 水平未达标 + 趋势走平或继续恶化 | **预警** |
| 任一期跳变（偏离近 8 季均值 >2σ）且无一次性事件解释 | **预警**，触发异常追因 |
| 现金类序列（OCF / 收现比）连续 2 季劣于净利序列 | **关注 → 预警**（利润含金量存疑） |

## 三、异常数据解读（先看异常，再读全篇）

读财报的第一性原理：**先找"不对劲"的地方，再决定深读哪里。** 异常数据 = 与历史趋势、同业表现、或三张表勾稽逻辑显著背离的数字。它往往是会计质量红旗、经营拐点或一次性事件的信号。异常扫描是维度一（财务健康度）的"探针"，也是维度二（读生意）的"警报器"——高 ROE 若伴随应收/存货异常，则 ROE 含金量要打折。

### 1. 异常的判定基准

- **序列背离（首要）**：当期值偏离自身季度序列轨道——跳变 >2σ、趋势斜率反转、或指标间序列分道扬镳（见第二节四条核心背离对）。**有季度序列时优先用这一条**，它比同业对比更贴合公司自身。
- **纵向背离**：单季/单年增速 vs 过去 3~5 年趋势（如营收常年 +10%，本期突然 +80%）。
- **横向背离**：公司与同业在同一周期的表现差（如行业都在去库存，它存货却暴增）。
- **勾稽背离**：三张表之间的逻辑不自洽（见下，最该优先查）。
- 判定阈值参考 `references/financial_health_criteria.md` 的红旗阈值；趋势类阈值见 `references/quarterly_trend_analysis.md` 第 5 节。

### 2. 六类高频异常与解读逻辑

| 异常类型 | 信号 | 背后的业务逻辑（怎么解读） |
|---|---|---|
| 应收 vs 营收背离 | 应收增速 > 营收增速、应收周转骤降 | 放宽信用促销售，收入质量差；可能压货/赊销，利润未真正变现 |
| 利润 vs 现金流背离 | 净利大增但 OCF/净利 下滑、收现比 <1 且恶化 | 利润未变现；警惕收入提前确认、赊销、费用资本化 |
| 毛利率异常跳变 | 突然跳升或跳降（且与同业方向不一致） | 跳升可能是真改善，也可能是少计提/成本资本化/收入确认激进；跳降可能是价格战、成本冲击或前期虚高回落 |
| 非经常性损益撑利润 | 扣非净利与归母净利缺口大 | 卖资产/政府补助/投资收益撑门面，主业其实在下滑 |
| 存货异常堆积 | 存货增速 > 营收增速且周转下降 | 滞销/跌价风险，未来减值将冲击利润 |
| 有息负债/商誉/关联交易异常 | 有息负债率陡升、商誉占净资产过高、关联交易占比大且定价不透明 | 财务脆弱、减值地雷或利益输送嫌疑 |

### 3. 解读动作清单（Workflow 前置）

- 拿到数据先扫四张财务"预警卡"：**应收、存货、现金流、非经常性损益**，再加两张：**序列背离卡、经营指标卡**；**每卡都对照季度序列看趋势**（是本期才恶化，还是已连续 3 季？），一次性跳变与趋势性恶化的处置完全不同。
- **经营指标卡的价值**：财务指标看不出的红旗，经营指标能看出来——销量上涨但单位净利连降 3 季（以价换量）、高端占比上升但毛利率下降（升级是降价冲的）、批发销量增速远超上险量（压货）。详见第四节第 3 点。
- 发现异常 → 必须**追因**：是一次性事件（注明口径、可降级为关注）？还是趋势性恶化（升级为预警）？
- 异常结论写进最终报告的「财务健康度」维度，作为**首要关注项**（见 `references/output_template.md`）。
- 若异常指向会计质量红旗，明确打「预警」并给出依据，不回避、不美化成中性表述。

### 4. 与三维度关系

异常扫描不是独立环节，而是贯穿全篇的"探针"：先扫异常锁定重点，再带着问题去读维度一/二/三，最后在综合判定里回扣——指引是否得到当期数据支撑、高 ROE 是否有水分。

## 四、行业与公司关键经营指标（KPI，贯穿全篇）

**核心命题：财务指标是结果，经营指标是原因。** 毛利率、ROE、现金流只能告诉你"变好了还是变坏了"；销量、单价、结构、份额、单位经济才能告诉你"为什么"以及"下一季该盯什么"。**只做财务比率的财报解读是不完整的**，缺了因果链与验证变量。

### 1. 五元组框架（选指标的总纲）

任何生意都拆成五个维度，按顺序问一遍，指标清单自然出来：

| 维度 | 问什么 | 例子（汽车 / 白酒 / SaaS） | 映射到哪个财务科目 |
|---|---|---|---|
| **量** | 卖出去多少 | 销量 / 销量吨数 / 客户数 | 营收分子 |
| **价** | 每个卖多少钱 | 单车均价 ASP / 吨价 / ARPU | 营收、毛利率 |
| **结构** | 卖的是什么组合 | 高端车占比 / 高档酒占比 / 大客户占比 | 毛利率、费用率 |
| **份额** | 相对对手如何 | 市占率 / 增速差（公司 − 行业） | 营收增速质量 |
| **单位经济** | 单个单位赚不赚钱 | 单车净利 / 吨毛利 / NDR、LTV/CAC | 净利率、ROIC、FCF |

### 2. 四条硬规则

1. **必做，不是选做**：每一次财报解读都要有经营指标章节，缺了等于只做了一半。
2. **核心 KPI 控制在 3~6 个**：选最能解释这家公司利润变化的几个，贪多稀释焦点。
3. **必须季度化**：经营指标与财务指标要建**同一时间轴的近 8 季序列**，否则无法做趋势判定、无法看背离。拿不到季度数据就标注「未获取」，并说明理由。
4. **派生指标一律用公式算**：ASP、单车净利、占比这类派生值用 `scripts/operating_kpi.py` 的 `derived` 公式定义计算，不手填——手填不可复算、易错。**口径必须在报告中写明**（如比亚迪 ASP 用汽车分部收入÷销量，含非整车业务，属趋势口径）。

### 3. 执行动作

1. **定位行业**：在 `references/industry_kpi_library.md` 里找到对应行业章节，取「必看指标清单」。行业不在库中 → 用该文件第 0 节的五元组自建法现场构造。
2. **收集数据**：公司月报/经营数据公告（销量、产量、用户数）→ 行业协会（市占率、景气）→ 财报分部与附注（分部收入、产能）→ 业绩会纪要（管理层常直接披露 ASP、产能利用率、订单）。数据源清单见第七节。
3. **建序列并算派生**：录入 JSON/CSV，跑脚本出表。
   ```bash
   python3 scripts/operating_kpi.py --input <kpi>.json --out html
   python3 scripts/operating_kpi.py --input <kpi>.csv  --derived derived.json --out md
   ```
4. **做趋势判定**：经营指标沿用第二节的「趋势诊断五看」与「趋势对健康度的修正规则」——完全同构，不做第二套标准。
5. **交叉验证（本节的价值所在）**：把经营指标序列与财务序列放一起看背离，命中下表任一形态即升级处置。

| 背离形态 | 含义 | 处置 |
|---|---|---|
| 量↑ + 单位净利↓ | 以价换量 / 降价促销 | 关注：看是否换到了份额 |
| 量↑ + 营收↓ | 单价崩塌（价格战或产品降级） | **预警** |
| 量↑ + 存货↑（快于量） | 压货，销量可能是批发口径堆渠道 | **预警**：对照终端销量（上险量/零售量） |
| 量↑ + OCF↓ | 利润没变成现金（账期放松 / 压货） | **预警** |
| 结构升级（高端占比↑）+ 毛利率↓ | 升级是假的，或高端品也在降价 | **预警**：查分价格带单价 |
| 份额↑ + 单位净利↓ | 烧钱换份额 | 关注：看单位经济能否随规模转正 |
| 单位成本↓ 慢于单价↓ | 规模效应跑不赢降价 | 预警：毛利率继续承压 |

### 4. 报告落位

- **1.5 行业与公司关键经营指标**：当期 KPI 快照 + 季度序列 + 派生指标 + 趋势特征（脚本产出）。
- **2.7 经营指标诊断**：用经营指标解释 2.1~2.6 的财务变化（人工撰写，本节是"为什么"的答案）。
- **五、综合结论的「主要风险与待跟踪项」**：每条风险都要落到**下一季可观测的经营指标**及口径，而不是"关注行业需求"这类无法验证的表述。

> 行业清单、口径陷阱、各行业的红旗，全部见 `references/industry_kpi_library.md`（汽车/比亚迪为最详细范本；银行/保险/券商的 KPI 就是监管口径核心指标）。

## 五、何时使用

- 用户输入公司名称或股票代码，要求「解读财报」「分析最新季报/年报」「业绩怎么样」「读生意」「生意模式怎么样」。
- 用户关心「近几个季度趋势怎么样」「是在改善还是恶化」「业绩是不是见顶了」——走第二节的季度序列诊断。
- 用户关心**行业与公司经营指标**：「单车价格 / 单车利润 / 高端车占比 / 市占率 / 客单价 / 吨价 / NDR / 同店增长 / 产能利用率怎么样」——走第四节的 KPI 框架。**这类问题本质上仍是财报解读**（经营指标是财务结果的上游变量），不要用纯行情技能应付。
- 用户关心「财报发布会 / 业绩说明会 / 电话会议说了什么」「业绩指引」「管理层怎么看 XX 业务」。
- 触发词：财报解读、业绩解读、季报分析、年报分析、异常数据、财务异常、季度趋势、单季拆分、读生意、生意质量、护城河、资本配置、股东回报、分红回购、业绩说明会、业绩指引、管理层发言、电话会议纪要、财报电话会；**经营指标类**：单车均价、ASP、单车净利、高端车占比、出口占比、市占率、市场份额、客单价、ARPU、吨价、NDR、续费率、同店增长、产能利用率、稼动率、单位毛利、单位成本、量价拆分。
- 不适用（转其他技能）：纯行情报价、买卖点/估值 → `wb-finance-skill` 或 `laotang-investment-framework`；公司护城河/竞争力深化 → `公司竞争力分析`。

## 六、工作流程

### 步骤 0：识别公司与确定财报期

- 将公司名称解析为「股票代码 + 市场」。优先用已连接的金融数据 MCP（`westock-mcp` / 腾讯自选股）的名称→代码对齐能力；若不可用，用 `WebSearch` 检索「XX 股票代码」。
- 确定「最新一期已披露财报」：优先取最近季度报告（Q1/Q3 季报、半年报、年报）。若最新季报尚未披露，则取最近年报 + 最新已知季报，并明确说明口径。**注意财年差异**（如微软 6 月年结、自然年公司与日历错开），报告头部须标注口径。
- 在报告头部记录数据时点与来源。

### 步骤 1：建立季度明细序列（趋势底座 · 前置）

在扫描异常之前，先把数据底座建好——**没有季度序列，异常扫描只能靠同业对比，抓不到公司自身的轨道偏离**。

- 用 `westock-mcp` 的 `data_finance` 取**近 8 季以上**（`num` = 期望输出期数 + 4，多头 4 期用于拆算首季）：
  ```json
  { "code": "sh600519", "num": 12, "fields": "core" }
  ```
  需要存货 / 应收 / 合同负债绝对额时，加 `{"type": "balance", "fields": "all"}`。
- 把返回体存成 JSON，调用脚本自动拆单季并出表：
  ```bash
  python3 scripts/quarterly_trend.py --input <file>.json --market A  --quarters 8
  python3 scripts/quarterly_trend.py --input <file>.json --market HK --quarters 4
  python3 scripts/quarterly_trend.py --input <file>.json --market US --fy-end 6   # 非自然年财年
  ```
- **必须人工复核三件事**（脚本会告警，但不能只看告警）：
  1. 官方 TTM 与自算 TTM 是否一致（差异 >2% 说明拆算或财年分组有误）。
  2. 序列首期是否为该财年首个报告期——否则该期单季不可拆，须补数据。
  3. 是否存在并表 / 会计政策变更 / 重述导致的「台阶式跳变」，有则标注并做可比口径说明。
- 输出：单季明细表 + TTM 表 + 趋势特征表（用 `--out html` 直接产出 HTML 片段，填入报告 1.2 / 1.3 节）。

### 步骤 2：异常数据扫描（基于序列的探针）

在已建好的季度序列上，用「三、异常数据解读」的预警卡做扫描（四张财务预警卡 + 序列背离卡 + 经营指标卡）：

- **应收预警卡**：应收增速 vs 营收增速、应收周转变化（**周转率只能同比同期比，见第二节硬规则 2**）。
- **存货预警卡**：存货增速 vs 营收增速、存货周转变化。
- **现金流预警卡**：OCF/净利润、收现比（营收现金含量）是否恶化——**看序列趋势，不只看当期**。
- **非经常性损益预警卡**：扣非净利 vs 归母净利缺口、非经常性损益构成。
- **序列背离卡**：逐条核对第二节的四条核心背离对（营收↑/应收周转↓、净利↑/OCF↓、归母↑/扣非走平、存货↑/营收走平）。
- **经营指标卡（须先完成步骤 3B）**：把经营指标序列与财务序列对齐，核对第四节第 3 点的七条背离形态（量↑/单位净利↓、量↑/营收↓、量↑/存货↑、量↑/OCF↓、结构升级/毛利率↓、份额↑/单位净利↓、成本↓慢于单价↓）。**经营指标能抓到财务指标抓不到的红旗**（如销量靠压货堆出来、高端占比靠降价冲出来）。
- 命中任一异常 → 记录「异常项 + 信号 + 初步判断（一次性跳变 / 趋势性恶化）」——**用季度序列区分二者**，这是本节的核心价值。
- 阈值与红旗标准见 `references/financial_health_criteria.md`；趋势类阈值见 `references/quarterly_trend_analysis.md`；经营指标的口径与行业红旗见 `references/industry_kpi_library.md`。

### 步骤 3：抓取基本财务数据（维度一 · 财务健康度）

按 `references/financial_health_criteria.md` 的指标清单获取并核算，**每个指标都要有当期值 + 趋势判定**：

- 营收与增速（单季 YoY、累计 YoY）
- 毛利率、净利率（及同比/环比变化，含非经常性损益影响）
- 归母净利润、扣非净利润、同比增速
- **ROE / ROIC**（回报率，巴菲特第一指标；拆解来源：净利率 / 周转 / 杠杆）
- **收现比**（营收现金含量 = 销售商品收到现金 ÷ 营收）
- 经营现金流净额、**自由现金流 FCF**（OCF − 资本开支）、OCF/净利润（利润含金量）
- 资产负债率、有息负债率
- **营运资本与周转**（应收/存货/应付周转、现金循环周期）
- **会计质量红旗**（非经常性损益、折旧政策、商誉、关联交易、收入确认）

数据来源优先级：

1. 已连接的金融数据 MCP：`westock-mcp` 的 `data_finance`（财报）、`data_quote`（行情/市值）。
2. 回退：`WebSearch` 检索公开财报（巨潮资讯、公司投资者关系官网、东方财富、雪球、财经媒体），并交叉核对关键数字。
3. 若某指标确实无法获取，明确标注「未获取」，不臆造。

> 银行/保险/券商：经营现金流、收现比、FCF 口径不同，**不适用**（见 `financial_health_criteria.md` 行业提示）；改看不良率、拨备、资本充足率、净息差、RORWA。
>
> **趋势口径要求**：上述指标凡涉及回报率（ROE / ROIC）与周转率，跨期比较一律用 TTM 或同比同期，禁止拿累计值跨季度直接比（见第二节硬规则 2）。

### 步骤 3B：行业与公司关键经营指标（KPI · 维度一的解释层）

**这一步是"为什么"的答案，不可跳过。** 财务数字说"毛利率下滑 2pct"，经营指标才能说"因为单车均价降了 5%，而单车成本只降了 2%，规模效应没跑赢降价"。执行细节、行业清单、口径陷阱见第四节与 `references/industry_kpi_library.md`。

1. **定位行业 → 取指标清单**：在 `references/industry_kpi_library.md` 找行业章节取「必看指标清单」，选 3~6 个核心 KPI；行业不在库中用第 0 节五元组自建。
2. **收集数据（近 8 季，与财务序列同期对齐）**：
   - 公司经营数据公告（销量、产量、用户数、门店数）、财报分部收入与附注（分部收入、产能）；
   - 行业协会（乘联会/中汽协/流通协会、统计局、第三方咨询）——市占率、景气、排产；
   - 业绩会纪要（管理层常直接披露 ASP、产能利用率、在手订单、结构占比）；
   - 回退用 `WebSearch`，但**研报估算值必须显式标注「估算」**，不得与实际值混用。
3. **录入并算派生**：写成 JSON（或 CSV + `--derived`），ASP / 单位净利 / 占比一律用 `derived` 公式定义，不手填。
   ```bash
   python3 scripts/operating_kpi.py --input <kpi>.json --out html   # 产出报告 1.5 节表格
   python3 scripts/operating_kpi.py --input <kpi>.json --out md     # 中间核对用
   ```
4. **做趋势判定**：沿用第二节的「趋势诊断五看」与「趋势对健康度的修正规则」，与财务指标同一套标准。
5. **交叉验证**：逐条核对第四节第 3 点的七条背离形态，命中即记入步骤 2 的「经营指标卡」，并在 1.4 / 2.7 节回扣。
6. **口径必须写明**：派生指标的分子分母来源、含不含非主业收入、批发口径还是终端口径，都要在报告里注明（如比亚迪 ASP = 汽车分部收入 ÷ 总销量，含非整车业务，属**趋势口径**，绝对值须与乘联会交叉验证）。

> 拿不到季度数据的指标，标注「未获取」并说明原因，**严禁用年度值插值为季度值或凭感觉拆分**。
>
> 银行/保险/券商的 KPI 就是监管口径核心指标（NIM、不良率、NBV、综合成本率、市占率等），见 `industry_kpi_library.md` 第 9 节。

### 步骤 4：读生意——生意质量与资本配置（维度二）

这是"读生意"的核心，按以下五个子维度分析（详见输出模板与判定标准）。**步骤 3B 的经营指标是本维度的直接输入**：定价权看 ASP 与单位毛利能不能守住，市场地位看市占率斜率，增长引擎看各业务线的量价拆分。

1. **回报率 ROE / ROIC（长期视角）**：连续 3~5 年水平与稳定性；拆解 ROE 来源——是高净利率（好生意）、高周转（运营强）、还是高杠杆（脆弱）。高杠杆型高 ROE 要打折。**结合步骤 2 的应收/存货异常与季度序列趋势，复核 ROE 含金量——ROE 连续下滑 3 季，即便仍在 15% 以上也要点名。**
2. **护城河与竞争地位**：壁垒类型（网络效应 / 转换成本 / 规模经济 / 品牌 / 牌照）、市场份额与定价权、与同业的相对位置。
3. **分部业务结构（增长引擎 / 利润池）**：各业务线的营收、利润率、增速；识别谁在贡献利润、谁在减速、谁在接力。**结合经营指标做量价拆分**：每个分部都要拆成「量 × 价 × 结构」，避免只报分部营收。
4. **资本配置与股东回报**：分红率/股息率、回购是否发生在低估时、并购记录与回报；对 Capex 用 ROI 视角（是否产生增量回报）而非只看投入额度。**用经营指标检验 Capex 效率**（如单车 Capex、单位产能投资、单店投资回收期）。
5. **同业对比（相对位置）**：与主要对手在增速、利润率、Capex、估值位置上的对照，相对位置比绝对值更能读出竞争态势。**同业对照优先比「经营指标的方向差」**（对手 ASP↑ 我↓ = 定价权在流失），绝对值差受产品结构影响太大。

### 步骤 5：检索业绩指引（维度三 · 管理层发言）

财报发布会/业绩说明会/电话会议的一手与二手纪要，结构化 MCP 通常不直接覆盖，主要靠 `WebSearch`：

- 检索词示例：「XX 2026 一季报 业绩说明会 纪要」「XX 财报电话会议 纪要」「XX 业绩交流会 实录」「XX 2025 年报 业绩说明会」。
- 优先来源：交易所「上证 e 互动 / 互动易」官方记录、公司 IR 官网、雪球/东财的会议纪要转载、财经媒体（证券时报、财联社、华尔街见闻）报道。
- 从纪要中提炼四类内容（详见输出模板）：
  1. **增长战略**：管理层对整体增长的定调、目标、路径。
  2. **产业发展**：行业景气判断、政策/技术趋势、竞争格局展望。
  3. **资本开支**：Capex 计划、产能扩张、研发投入、并购意向（补充 ROI/回报视角）。
  4. **关键业务模块发言**：分业务板块的经营数据与展望（分产品/分地区/分客户），管理层重点强调的方向。
- 标注每条指引的「来源」与「管理层原话 vs 分析师/媒体转述」，避免把研报观点当管理层发言。
- **补充**：对照「管理层历史指引兑现率」——上期指引落地了多少，作为诚信与执行力的参考。
- **回扣异常与趋势**：指引是否与步骤 2 的异常、当期财务数据矛盾（如喊增长但营收序列已连续 3 季下滑、高 Capex 但现金流序列紧张）。**用季度序列验证指引的兑现轨迹**——上期指引在后续几个季度是否逐季落地。

### 步骤 6：综合健康度判定

- 对每个财务维度给出「健康 / 关注 / 预警」三档结论，并给出依据（阈值见 `references/financial_health_criteria.md`）。**步骤 2 命中的异常项作为首要关注/预警项列出。**
- **每个维度都要叠加趋势修正**：先判水平，再看近 4 季斜率与连续同向期数，按第二节第 4 点的修正规则表调整档位。最终档位须能回答「在变好还是变坏」，不能只给当期静态结论。
- **经营指标单独给一档结论**（依据 `references/industry_kpi_library.md` 的行业基准与第四节第 3 点的背离表）：量/价/结构/份额/单位经济各给方向判断，并合成一句「这门生意的单位经济在改善还是在恶化」。**经营指标与财务指标结论冲突时，以经营指标为准并解释差异**——经营指标是先行变量（如销量已连续 3 季下滑，但营收靠 ASP 提升还在涨，说明增长不可持续）。
- 将生意质量（维度二）与财务数据（维度一）对照：高 ROE 是否靠真本事还是杠杆？高净利是否被非经常性损益扭曲？
- 将业绩指引与财务现状对照：指引是否得到当期财务数据支撑？有无矛盾（如高 Capex 但现金流紧张、喊增长但营收下滑）。
- **用经营指标验证指引**：管理层喊的增长/高端化/降本，在经营指标序列上有没有对应的轨迹（如喊高端化，高端车占比是否逐季提升；喊降本，单位成本是否逐季下降）。指引与经营指标背离时，明确写「指引未获经营数据支撑」。

### 步骤 7：产出报告（HTML 网页）

- **交付格式为 HTML 网页**。复制 `assets/report_template.html` 作为骨架（已含全部样式、章节结构、目录锚点与占位符），逐项替换 `{{占位符}}` 与示例数据行。模板自包含、无外部依赖，可直接双击打开。
- **章节内容写什么**见 `references/output_template.md`——它定义每节的写作要求，HTML 模板定义长什么样，两者章节一一对应。
- 季度明细各表由脚本直接产出 HTML 片段，粘贴进 1.2 节对应位置即可：
  ```bash
  python3 scripts/quarterly_trend.py --input <file>.json --market A --quarters 8 --out html
  ```
- 经营指标各表同理，由 `scripts/operating_kpi.py` 产出 HTML 片段，粘贴进 1.5 节：
  ```bash
  python3 scripts/operating_kpi.py --input <kpi>.json --out html
  ```
- **配色规范（模板已内置，勿改语义）**：
  - **数值涨跌 → 红涨绿跌**（A 股习惯）：`.up` 红 / `.down` 绿，**只用于同比、环比、斜率等「变化量」**；水平值（销量、毛利率、ASP、占比）不着色——它是水平不是涨跌。
  - **健康度档位 → 风险语义**：`.badge.h` 健康（绿）/ `.badge.w` 关注（琥珀）/ `.badge.d` 预警（红）。
  - 两套语义不同，不可混用——不要把「同比下降」标成绿色档位徽章。
- 数据缺口一律在单元格内写「未获取」，不删行、不留空、不臆造。
- 默认保存为：`{公司名}_财报解读_{YYYY}Q{n}.html`，存入当前 workspace 根目录（用户可改路径）。
- 头部写明数据时点、来源、方法声明与季度序列长度；尾部保留免责声明。报告「财务健康度」章节须依次呈现：**当期快照 → 季度明细表 → 趋势诊断 → 异常扫描结论 → 行业与公司关键经营指标（1.5）**。
- 生成后用 `present_files` 打开预览，确认表格渲染正常、无未替换的占位符残留。

## 七、数据源与可靠性

- 已连接 MCP 优先（当前：`westock-mcp` 腾讯自选股）。**不要调用 disconnected 的金融 MCP**（如东方财富妙想、Wind、进门投研等）。
- 季度序列取数：`data_finance` 的 `num` 至少为输出期数 + 4；A 股用 `fields=core`，需存货/应收绝对额时加 `type=balance, fields=all`；港股无扣非、无销售收现、无 TTM 字段，一律标注「未获取」，不臆造、不用代理指标硬套（字段映射见 `references/quarterly_trend_analysis.md` 第 2.2 节）。
- 业绩指引几乎必须靠 `WebSearch`；检索时优先官方与一手来源，明确区分「管理层原话」与「媒体/分析师转述」。
- **经营指标（KPI）数据源**：公司经营数据公告 / 月报（巨潮、港交所）→ 行业协会（乘联会、中汽协、流通协会、统计局、第三方咨询）→ 财报分部与附注 → 业绩会纪要 → `WebSearch` 回退。详见 `references/industry_kpi_library.md` 附录的「常见数据来源」。
  - **行业销量、市占率、终端上险量这类数据通常不在结构化 MCP 里**，主要靠 `WebSearch` + 行业协会公开数据，须注明来源与时点。
  - 研报/第三方估算值必须显式标注「估算」，不得与实际披露值混用或冒充实际值。
- 所有关键数字必须可核验；拿不到就标「未获取」，严禁臆造、严禁把年度值插值成季度值。

## 八、与其他技能的衔接

- **估值/买卖点**：本技能不做估值。财报解读完成后如需估值，转 `laotang-investment-framework`（适用轻资产成长股）或 `wb-finance-skill`。
- **公司竞争力/护城河**：维度二的护城河判断如需深化，配合 `公司竞争力分析` 技能。
- **同业对比**：维度二的同业对照可结合 `westock-tool` 选股 / `wb-finance-skill` 获取对手数据。
- **行业与产业链**：需要行业总量、供需格局、产业链位置时，配合 `industry-analysis` 技能——它的行业数据可作为本技能经营指标的**分母**（行业销量、行业规模）。
