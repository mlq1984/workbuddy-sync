# 首次覆盖报告生成 (equity-coverage-report)

生成专业卖方/买方风格的公司首次覆盖研究报告（Markdown + PDF），适用于股票、ETF、行业指数。

---

## 适用场景
- 为某只股票/ETF/行业生成首次覆盖报告（initiation report）
- 生成买入/卖出/持有评级 + 目标价
- 撰写 DCF 估值、可比估值、SWOT 分析
- 团队晨会材料、投资委员会材料

## 触发词
首次覆盖报告、initiation report、覆盖报告、公司深度研究、深度研报、股票研究报告、评级、目标价、估值分析

---

## 一、报告结构（9 节标准框架）

| 节 | 标题 | 必须字段 |
|----|------|---------|
| 1 | 执行摘要 | 评级、目标价、12个月预期回报、核心论点（3 条） |
| 2 | 公司概况 | 业务结构、收入构成、市场份额、管理层 |
| 3 | 行业分析 | 行业规模、增速、竞争格局、关键趋势 |
| 4 | 财务分析 | 近 3 年营收/净利润/毛利率/ROE/负债率 |
| 5 | 估值分析 | DCF 或 可比估值（PE/PB/PS），显式列出 WACC 等关键假设 |
| 6 | 风险提示 | 3-5 个核心风险 |
| 7 | 目标价与评级 | Buy/Hold/Sell + 12 个月目标价 + 催化剂 |
| 8 | 附录 | 数据源、免责声明 |
| 9 | (可选) 管理层评论 | 电话会要点 |

---

## 二、数据获取规范

### 数据来源
- **A股**：东方财富 (https://quote.eastmoney.com)、同花顺 (https://q.10jqka.com.cn)
- **港股/美股**：Yahoo Finance、东方财富国际
- **财务数据**：东方财富 F10、巨潮资讯 (https://www.cninfo.com.cn)
- **行业数据**：国家统计局、Wind（如有）、公司公告

### 数据时效规则
- 财务数据：以最新季报/年报为准
- 股价数据：以最近交易日收盘价为准
- 超过 90 天的数据标注 `[STALE]`
- 无法获取的数据标注 `[MISSING]`，绝不编造

### 数据验证
- 财务数据交叉验证（至少 2 个来源）
- 估值倍数与市场可比公司对比
- 管理层指引 vs 历史表现的偏差

---

## 三、估值方法

### DCF（现金流折现）
```
WACC = 无风险利率 + Beta × 股权风险溢价
终端增长率：取 GDP 增速或行业长期增速（通常 2-3%）
折现期：5 年预测期 + 永续期
```

### 可比估值（Comps）
- 选择 3-5 家同行业、同规模可比公司
- 核心倍数：PE(TTM)、PE(Forward)、PB、PS、EV/EBITDA
- 给出行业中位数和分位数

### 关键假设必须显式列出
| 假设 | 典型取值 | 标注 |
|------|---------|------|
| WACC | 8-12% | 模型输出 |
| 终端增长率 | 2-3% | 假设 |
| 预测期 | 5 年 | 假设 |
| 净利润 CAGR | 按历史/指引推算 | 判断 |

---

## 四、评级与目标价规则

### 评级体系（三档制）
| 评级 | 含义 | 12个月预期回报 |
|------|------|---------------|
| Buy（买入） | 预期涨幅 >15% | 积极推荐 |
| Hold（持有） | 预期波动 ±15% | 暂不建议交易 |
| Sell（卖出） | 预期跌幅 >15% | 建议减持 |

### 目标价推导
- 必须说明目标价的计算方法（DCF 输出 / 可比估值 / 管理层指引）
- 给出目标价区间（乐观/中性/悲观）
- 明确催化剂时间表

---

## 五、生成流程（Step-by-Step）

```
Step 1: 明确标的 → 确定股票代码 + 市场
Step 2: 收集数据 → 使用 WebFetch 抓取东方财富/同花顺
Step 3: 行业分析 → Porter's Five Forces / SWOT
Step 4: 财务分析 → 杜邦分析 / 现金流分析
Step 5: 估值建模 → DCF 或 Comps，显式列出假设
Step 6: 风险识别 → 至少 3 个核心风险
Step 7: 评级 + 目标价 → 给 Buy/Hold/Sell + 12个月目标价
Step 8: 撰写报告 → Markdown 格式，9 节标准结构
Step 9: 合规审查 → 添加免责声明 + 数据源标注
Step 10: 可选 PDF → 调用 huashu-md-to-pdf 技能生成
```

## 六、PM 七问（研究质量自检）

1. **什么被错误定价了？**（无变异认知 → 降级为"监控项"）
2. **当前价格反映了什么？**
3. **什么能证明论点？**
4. **什么能推翻论点？**
5. **为什么是现在？**
6. **什么会改变仓位/评级/目标价？**
7. **还缺少什么证据？**

## 九、注意事项

1. **绝不编造数据**：[MISSING] 或 [STALE] 明确标注
2. **关键假设显式**：WACC、终端增长率、预测期必须列明
3. **结论带评级**：Buy/Hold/Sell，附目标价和时间维度
4. **区分事实与判断**：每个主张标注类型
5. **合规声明**：报告末尾统一添加免责声明
6. **多源验证**：财务数据至少 2 个来源交叉验证
