# Ai公益生图Pro

**四运行中心 + 提示中心智能生图工作台**（通知中心 · 通道中心 · 生成中心 · 结果中心 · 提示中心）。

- **双屏工作台**：通道中心（各通道 Key 获取/验证/开关）+ 作品中心（实时画廊、单击预览、复制/删除、Ctrl+滚轮缩放与拖拽）。
- **Agent 动线 = 主流程五步 + 提示中心**：理解并检测内容 → 判断并推荐通道（`--status`）→ 双选项（通道可多选 + 是否优化提示词）→ 提示中心（`prompt_center/`，用户选优化时）→ 组装通用 spec → `POST /api/execute` → 引路汇报；`--jobs / --job <id>` 查询结果。
- **提示中心**：生图前提示词优化（供需审查/优化模式/分析参数/撰写/润色/质量审查），流程见 `prompt_center/方法论.md`，场景骨架见 `prompt_center/templates/`。
- **体验协商**：可选参数（比例/清晰度/张数）由参数中心逐通道自动协商（不支持就近降级），免费额度通道自动补体验档；硬能力不匹配才剔除通道。
- **通道即插即用**：`channels/<id>/` 自包含（app.py + api.md，取 Key 方式见各 api.md），可选声明 `CAPS`/`translate`；增删通道零改核心。
- **存储**：产物平铺直存缺省根 `桌面\Ai公益生图Pro\`（命名 `通道_日期_时间_毫秒.ext` 并登记 img.json）；工作台 ⚙ 可运行时改关联位置并自动迁移现有图片。
- **启动**：`python 启动.py`（127.0.0.1:8765，自动打开浏览器工作台）。
- 纯 Python 标准库，零第三方依赖；内含多条免费生图线路（Pollinations / Agnes ai / 日日新 / 智谱 / Cloudflare / Aurora绮梦绘）。
