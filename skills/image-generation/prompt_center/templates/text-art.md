# T3 文字图/标语/日签 / Typography Card & Daily Quote
- **识别信号**：用户说"写 XX 字/标语/金句/日签/文字卡片"。（EN: typography card, quote image, daily sign）
- **比例**：`1:1` 或 `9:16`（日签类）。
- **版面骨架**：文字即主体，占画面约 1/3，居中或黄金分割位 → 背景极简（纯色/淡纹理/弱化摄影背景）→ 小装饰（边框/印章/线条）→ 日签加日期角标（角落小字）。取法"概念字体海报"：让字体成为画面主角，标题**逐字精确拼写**，人物/物体/风景（若有）服务文字含义。
- **配色**：文字与背景**高对比双色**（如深墨底 + 浅字，或浅底 + 深字）；书法类可用墨 + 金/朱点缀；色系克制，不堆色。
- **文字规则**：文案由你从需求**智能提炼**（短、少、清楚最宜，≤20 字最稳，绝不搬运用户原话）；字体三系按气质选——**书法体**（传统/祝福）、**黑体**（现代/有力）、**手写体**（温柔/生活）；横排为主，竖排限书法类；强制"文字清晰锐利，无重影无重叠，与背景对比鲜明"。**中文文字 buff（用智谱/商汤/aurora 等 capable 模型时）**：指定字体（如微软雅黑/书法体）+「笔画清晰、无粘连、无错别字、字号≥24」；**Flux 通道(cf/free)不要写中文文字**——改为「留白区域 + 后期 PS/稿定叠字」，Flux 渲中文弱且易伪字。
- **避坑**：字多必乱码；生僻字艺术字易崩；对比不足；非书法类用竖排易怪；文字除非指定绝不擅加。
- **排除句式**："单张成品，不要字体展示板/过程稿/水印样张"；文字渲染用"逐字精确拼写 + dominant 地位"句式。
- **任务句范式**：中文「生成一张完成的文字日签图，画面主体为文字"…"」/ EN "Create ONE finished typography card featuring the exact text '...'"
- **EN Quick Reference** — Triggers: quote/typography/daily card · Layout: text as hero (~1/3), minimal bg, date corner; typography-as-hero, exact spelling · Color: high-contrast two-tone, restrained · Fonts: calligraphy/heiti/handwrite by mood · Pitfalls: too many chars, rare glyphs, low contrast, off-mood vertical text, unsolicited text · Exclusions: single piece, no font showcase sheet/process draft; exact spelling + dominant text.
