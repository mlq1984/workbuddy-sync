# T11 建筑/空间效果图 / Architecture & Interior Rendering
- **识别信号**：用户说"室内设计/装修/户型/建筑外观/庭院/民宿/城市地图"。（EN: interior, renovation, architecture, exterior, courtyard, city map）
- **比例**：`16:9`（外观/横厅）或 `3:4`（竖向空间）。
- **版面骨架**：透视明确（室内**一点/两点透视**，写清视角与站位）→ 材质真实（木/石/布艺/金属，写明质感）→ 光线氛围（晨光/黄昏/夜景灯光，写明时间）→ 空间层次（前景陈设/中景家具/全景纵深）。分支：室内（家具软装 + 材质细节）vs 外观（体量造型 + 环境关系 + 天光）；地图需地标/标签/边框/准确度。取法 guizang：真实建筑/在地文化照片→编辑海报，主体域/背景域/互动域在缩略尺度皆可见。
- **配色**：建筑材质色（混凝土灰/木/石/玻璃）+ 环境光；空间气质统一，不堆多彩。
- **文字规则**：无字；带说明的设计需求走 T4 信息图；地图标签语言与相对位置锁定。
- **避坑**：透视错误（必须写明视角与消失方向）；家具比例失真；反光过度像 CG（写"自然光、真实材质"）；不合理透视（概念图除外）；地图标签语言错位；双居中孤岛（主体居中+标题居中互不接触）。
- **排除句式**："单张成品效果图，不要平立面图纸/标注尺寸线"。
- **任务句范式**：中文「生成一张完成的…空间效果图：…」/ EN "Create ONE finished interior/exterior rendering: ..."
- **EN Quick Reference** — Triggers: interior/renovation/exterior/courtyard/map · Rules: explicit perspective + true materials + timed lighting + depth layers; interior vs exterior; map landmarks+labels · Color: material palette + ambient light, unified · Pitfalls: skewed perspective, wrong furniture scale, CGI sheen, impossible perspective (non-concept), map label mismatch, double-centered island · Exclusions: single rendering, no floor-plan/blueprint with dimensions.
