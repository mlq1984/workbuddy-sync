# T10 演示/教学配图 / Slides & Teaching Diagram
- **识别信号**：用户说"PPT 配图/讲解图/步骤图/示意图/教程图/爆炸图"。（EN: slides, diagram, step-by-step, explainer, exploded view）
- **比例**：`16:9`（演示页标准）。
- **版面骨架**：步骤序号醒目（①②③）→ 图示为主、文字为辅 → 逻辑流向（箭头/时间线）→ 风格统一二选一（**扁平矢量** / **等距 3D**）。文档页式：定义分栏/目录/图表系统/字体层级；信息图：3–5 模块 + 信息流 + 层级；爆炸图/标注：产物类型/组件/标签/材质逻辑/展示格式，清晰标注 + 受控技术风。单图讲清一个概念。
- **配色**：教学用**清晰高对比**（深浅分明、不靠多彩）；技术/科学图冷色系（蓝/青/灰）+ 强调色标注；全图色系统一。
- **文字规则**：步骤标签 ≤6 字/个；序号明显；能画图示意就不用文字块；强制渲染约束。
- **避坑**：小字乱码（教学图文字最少化）；一幅图内风格混搭；信息块 >4；箭头逻辑不清；密集小字；图表错对齐；组件关系不清。
- **排除句式**："单页成品，不要整套幻灯片缩略拼版"。
- **任务句范式**：中文「生成一张完成的步骤示意图：…」/ EN "Create ONE finished step-by-step diagram: ..."
- **EN Quick Reference** — Triggers: diagram/steps/explainer/slides/exploded · Layout: numbered steps, visual-first, arrow flow, flat or isometric (pick one); doc grid + infographic modules + exploded labels · Color: high-contrast teaching palette, cool scientific + accent · Text: ≤6 chars per label · Pitfalls: tiny text, mixed styles, >4 blocks, unclear flow, dense text, misaligned chart, unclear components · Exclusions: single page, no slide-deck thumbnail board.
