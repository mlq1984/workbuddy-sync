# T13 漫画/分镜/多格叙事 / Comic & Storyboard
- **识别信号**：用户说"漫画/分镜/四格/连环画/故事板/多格叙事"。（EN: comic, storyboard, multi-panel, four-frame manga）
- **比例**：单页 `3:4` 或 `4:3`。
- **版面骨架**：**格数明确**（2/4/6 格，写"six panels"）→ 排布声明（网格 或 **对角线错落** diagonal layout）→ **阅读动线声明**（"clear reading flow，从左到右/从上到下"）→ 对话气泡（speech bubbles，挂在说话者头顶）→ 跨格叙事连贯。取法 scene-storytelling：定义 who/where/when/conflict/emotion/机位，场景细节服务故事；illustration：构图/主体/配色/笔触材质/情绪/完成度，参考图锁角色识别；character 设定表：锁身份锚点/服装/比例/动作数（≤防拥挤）。
- **配色**：分镜内**统一光源与色调**；跨格保持角色配色一致；不靠多彩堆砌。
- **文字规则**：气泡对白**极短**（≤8 字/气泡）；旁白框（顶部/底部）；拟声词可点缀；角色一致性**必须显式写**："保持角色面部、发型、服装在所有格中一致"。
- **避坑**：格数多叙事乱（≤6 格最稳）；角色跨格变脸（一致性声明不可省）；气泡文字过长溢出；动线不清读者看不懂顺序；只写风格不写构图；角色识别漂移；动作间服装变化；通用幻想背景。
- **排除句式**："单页多格成品，不要单格重复/未上色草稿/分格过程稿"。
- **任务句范式**：中文「生成一页完成的四格漫画：…」/ EN "Create ONE finished comic page with four panels: ..."
- **EN Quick Reference** — Triggers: comic/storyboard/multi-panel · Layout: explicit panel count (2/4/6), grid or diagonal layout, clear reading flow, speech bubbles; who/where/when/conflict/emotion/framing · Color: unified light & tone per page, consistent character palette · Text: ≤8 chars per bubble, consistent character declaration mandatory · Pitfalls: >6 panels chaos, character drift, bubble overflow, unclear order, style-only-no-composition, generic fantasy bg · Exclusions: single multi-panel page, no repeated single panels/uncolored drafts.
