# T1 宣传海报 / Promotional Poster
- **识别信号**：用户说"海报/宣传/活动/招募/通知"类。（EN: poster, promo, event, recruitment, announcement）
- **比例**：竖版 `3:4` 或 `9:16`（默认假设：竖版，需声明）；宽幅横幅 `21:9`。
- **版面骨架（自上而下）**：主视觉占上 2/3（产品/人物/插画场景三选一，主体占画面 40~60%）→ 大标题（压图底部渐变遮罩上，或图下独立行，1 行为主）→ 副文案/时间地点（底部小字区，≤2 行）→ 品牌元素（角标位）。分支形态：①概念字体海报——字体即主视觉，标题**逐字精确拼写**，人物/物体/风景服务标题含义；②水墨/诗意海报——人像剪影 + 水墨质感 + 留白，构图安静高级、可读，非必要不写文字；③科普/活动海报——清晰主体 + 少量文案 + 柔影 + 充足留白，标签短而清楚；④运动/商业 Campaign——定义运动/姿态/核心道具/标题/品牌色，强光影、干净构图、可读数据层。
- **配色**：主色 ≤3，限定色系（不混搭情绪板）；高级感来自克制而非堆色；标题/主视觉与背景对比鲜明。
- **文字规则**：标题 ≤10 字/行；字号三级"大标题 > 副文案 > 小字"；全图主色 ≤3；强制"文字清晰锐利，无重影无重叠，与背景对比鲜明"。
- **避坑**：文字压花哨背景必糊；元素挤满画面（留白呼吸）；标题被主视觉遮挡；主色超过 3 种显廉价；混合情绪板；标题错字；廉价奇幻拼贴；装饰符号过多。
- **排除句式**：显式排除过程性产物——"单张成品海报，不要拼贴/草图/moodboard/多方案展示"。
- **任务句范式**：中文「生成一张完成的竖版宣传海报：…」/ EN "Create ONE finished vertical promotional poster: ..."
- **EN Quick Reference** — Triggers: poster/promo/event · Layout: hero visual top 2/3, headline below, sub-copy bottom, brand mark corner; branches: typographic / ink-double-exposure / science / sports-campaign · Color: ≤3 colors, restrained palette · Text: ≤10 chars/line, 3-tier hierarchy, sharp legible · Pitfalls: text on busy bg, clutter, occlusion, cheap palette, mixed moodboard, misspelled title, fantasy collage · Exclusions: single final piece, no collage/sketch/moodboard/multi-variant board.
