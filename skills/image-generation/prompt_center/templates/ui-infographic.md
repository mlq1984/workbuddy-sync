# T4 UI/信息图 / UI & Infographic
- **识别信号**：用户说"UI/界面/信息图/图表/流程图/说明图/科普图解"。（EN: UI screen, infographic, chart, flowchart, explainer）
- **比例**：`16:9`（演示/网页）或 `9:16`（手机界面）；标注图解另见 T14。
- **版面骨架**：网格 2~4 信息块 → 标题区 → 图标+短标签 → 统一圆角与间距语言；**设备语境写明**（手机界面/网页/看板）；深浅模式按用户说明（默认浅色）。信息图：定义 3–5 模块 + 信息流 + 层级 + 短标签，色块/箭头/图标/留白控复杂度；尺度缩放图：6–8 尺度框，每框短标签 + 单位 + 倍率 + 不同尺度细节（避免全同/通用放大镜）。UI 锁状态栏/Tab/操作区/评论层。
- **配色**：信息分区用**色组**（冷暖区分模块），不靠多彩堆砌；背景与卡片对比清晰；避免长段正文入图。
- **文字规则**：标签 ≤8 字/块；序号清晰；强制渲染约束。
- **避坑**：小字乱码（文字最少化）；块数 >4；透视变形（写"正视角、平视"）；风格混搭；平台描述过泛；文字可读性失守；模块过多。
- **排除句式**："单一界面/图表成品，不要多屏拼贴/设计流程稿/标注图层"。
- **任务句范式**：中文「生成一张完成的…界面/信息图」/ EN "Create ONE finished UI screen / infographic: ..."
- **EN Quick Reference** — Triggers: UI/infographic/chart · Layout: 2–4 grid blocks, title zone, icon+label, device context, light mode default; infographic 3–5 modules + flow; scale diagram 6–8 frames · Color: grouped palette per module, clear contrast · Text: ≤8 chars per label · Pitfalls: tiny text, >4 blocks, perspective skew, mixed styles, vague platform, unreadable text, too many modules · Exclusions: single screen/chart, no multi-screen collage/annotated layers.
