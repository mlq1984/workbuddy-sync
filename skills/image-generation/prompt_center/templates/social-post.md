# T7 社交媒体配图（小红书/微博/朋友圈）/ Social Media Post
- **识别信号**：用户说"小红书/微博/朋友圈/种草/分享图/品牌内容"。（EN: xiaohongshu/RED, social post, brand content, share image）
- **比例**：`3:4` 竖版（小红书标准，默认假设）；Story `9:16`；Pinterest `2:3`。
- **版面骨架**：封面首图 = 大字标题（≤10 字，视觉中心）+ 生活化场景主体；内页图文字少、以内容为主；**多图系列锁"品牌 DNA"** = 品牌原型 / 色世界(3–4 色) / 光签名 / 环境族 / 排版位，全系列一致。平台规格：IG 1:1 或 4:5（主体居中三分之一）；Story 9:16（上 15% 下 20% 留空）；Pinterest 2:3 竖版；Hero 16:9/21:9。
- **配色（品牌原型→视觉语言）**：Luxury 黑金 + 戏剧光 / Clean Living 白+sage+奶油+木 + 柔自然光 / Urban 水泥灰+霓虹 + 混合环境光 / Sporty 高饱和原色 / Vintage 琥珀+芥末+焦橙 + 暖钨丝。全系列一致。
- **文字规则**：标题大字高对比；整体**生活感/自然光**（反精致棚拍感）；四边留白（防平台 UI 遮挡）。
- **避坑**：过度精致显假（写"生活感、自然光、随手拍质感"）；文字压边被裁；首图信息过载；摆拍僵硬；过度制作棚感；水印；主体贴边被 UI 遮。
- **排除句式**："单张成品，不要九宫格拼图"（多图 = 分次 spec）。
- **任务句范式**：中文「生成一张完成的社交分享封面图：…」/ EN "Create ONE finished social post cover: ..."
- **EN Quick Reference** — Triggers: RED/xiaohongshu/social share/brand content · Layout: bold title center + lifestyle subject, UI-safe margins, series DNA consistency; specs IG 1:1/4:5, Story 9:16, Pinterest 2:3, Hero 16:9/21:9 · Color: brand-archetype palette, consistent across set · Text: ≤10 chars headline, natural vibe · Pitfalls: over-polished, edge crop, overloaded cover, stiff pose, studio feel, watermark, UI overlap · Exclusions: single piece, no 9-grid collage.
