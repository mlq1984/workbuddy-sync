## 云舟科技（B2B · 企业 SaaS（销售/渠道管理软件））

### 场景
PaaS战略转型期，需要通知全员技术部+产品部共55人，技术栈从项目定制转向PaaS平台。涉及技能转型、工作方式变化、考核标准调整。敏感度高（技能焦虑+考核变化）。

### 输出

#### 一、沟通场景识别
| 要素 | 内容 |
|------|------|
| 主题 | PaaS战略转型——技术栈升级与工作方式调整 |
| 目的 | 说服（改变工作方式）+ 告知（转型计划）+ 安抚（技能焦虑） |
| 受众 | 管理层(7人)→资深工程师(12人)→中级工程师(20人)→初级工程师(8人)→产品部(10人) |
| 敏感度 | 高（涉及技能转型/考核标准/组织调整） |

#### 二、沟通模板

**第一波：管理层预沟通（T-14天）**
- 渠道：1on1面谈（CTO→技术经理，每人30分钟）
- 正文要点：① 转型商业理由（毛利15%→60%）② 时间表 ③ 你需要做什么 ④ 你团队可能的反应和应对
- 禁忌：✗不说"不转型就走人" ✗不说"你们技能过时了"

**第二波：全员告知（T-10天）**
- 渠道：全员大会（CTO主讲60分钟）+邮件确认
- 正文：
```
主题：【重要】PaaS战略转型——技术栈升级计划

各位同事：

为响应市场变化和客户需求，公司决定从项目定制模式转向PaaS平台化模式。
这一转型将使我们的产品交付效率提升50%，毛利率从15%提升至60%。

【转型计划】
- Q3：PaaS MVP上线，首批3个种子客户
- Q4：PaaS功能完善，10个客户上线
- Y2：PaaS收入占比50%+

【对您的影响】
- 技术栈：从[旧技术]迁移至[新技术]，公司提供全套培训+认证补贴
- 工作方式：从瀑布开发转为敏捷迭代，每日站会+两周冲刺
- 考核标准：过渡期6个月双轨考核（旧项目+PaaS各占50%）

【支持保障】
- PaaS技术培训4场（外部专家+内部分享）
- 认证补贴¥5K/人
- 创新容错基金¥50K（失败不扣绩效）
- 技术经理1on1答疑（本周内预约）

我们理解转型带来不确定性。请相信：公司的投入（培训/补贴/容错）说明这不是"要求你们变"，而是"陪你们一起变"。

如有疑问，请联系CTO或HRD。

—— CEO & CTO
```
- 禁忌：✗不用"削减""淘汰""强制" ✗不在周五下午发

**第三波：部门Q&A跟进（T-7天）**
- 渠道：部门会议（各组长主持，30分钟）
- 要点：收集疑问→现场解答→记录未决问题→48小时内回复

#### 三、注意事项
| 注意点 | 说明 |
|--------|------|
| 信息分级 | 管理层(全貌)→全员(方向+影响+支持)→个人(1on1具体影响) |
| 法律合规 | 培训补贴协议/考核标准变更须书面确认 |
| 文化适配 | "创新驱动"价值观——将转型包装为"创新升级"而非"技能淘汰" |

#### 四、后续跟进
| 时间 | 动作 | 指标 |
|------|------|------|
| T+3天 | 匿名问卷收集反馈 | 理解度≥80%、接受度≥60% |
| T+7天 | 1on1覆盖所有资深工程师 | 焦虑度下降50% |
| T+14天 | 培训报名确认 | 报名率≥90% |

## 悦己美妆（B2C · 美妆电商（自有品牌·多渠道销售））

### 场景
成熟期88人，推行核心岗位SOP体系（客服/仓储/直播）。涉及工作方式从"经验驱动"转为"流程驱动"。敏感度中高（习惯改变+部分员工可能感觉"被管控"）。

### 输出

#### 一、沟通场景识别
| 要素 | 内容 |
|------|------|
| 主题 | 核心岗位SOP体系上线——从"经验驱动"到"流程驱动" |
| 目的 | 告知（SOP计划）+ 说服（接受流程化）+ 征询（参与设计） |
| 受众 | 管理层(4人)→客服组(18人)→仓储组(20人)→直播组(15人) |
| 敏感度 | 中高（习惯改变+创作自由顾虑） |

#### 二、沟通模板

**第一波：管理层+组长预沟通（T-10天）**
- 渠道：管理层会议（COO主持，60分钟）
- 要点：① SOP必要性（满意度波动±20%）② 设计框架 ③ 你需要做什么（参与编写）

**第二波：全员告知（T-7天）**
- 渠道：全员大会（CEO主讲30分钟）+IM群确认
- 正文：
```
主题：【通知】核心岗位SOP体系上线计划

亲爱的伙伴们：

感谢大家一直以来的辛勤付出！正是你们的专业和经验，让悦己美妆走到了今天。
为了让大家的工作更轻松、更高效，我们计划在Q3上线核心岗位SOP（标准作业流程）。

【为什么做SOP】
- 让新人上手周期从45天→20天（减少新人的迷茫期）
- 让满意度波动从±20%→±5%（减少"看人下菜"的不一致）
- 让大家的经验变成可传承的知识（不依赖某个人）

【SOP范围】
- 客服组：咨询话术/退换货流程/投诉处理
- 仓储组：入库/拣货/打包/出库标准流程
- 直播组：后台流程（排班/数据/选品）——直播内容不做SOP！

【你需要做什么】
- 参与SOP编写（你的经验最宝贵）——编写者有奖金奖励
- 试用SOP并提出改进建议

【支持保障】
- SOP编写培训+模板支持
- 2周过渡期，期间不考核SOP执行
- 编写奖金¥3K/组

这不是"管着大家"，而是"让大家的经验沉淀下来"。你的每一个最佳实践，都将成为悦己美妆的宝贵资产。

如有疑问，请联系COO或HRD。

—— CEO
```
- 禁忌：✗不说"规范化你们" ✗不说"杜绝个人随意性"

#### 三、注意事项
| 注意点 | 说明 |
|--------|------|
| 信息分级 | 直播组特别说明"直播内容不做SOP"——消除创作自由顾虑 |
| 文化适配 | "快乐工作"价值观——强调"让工作更轻松"而非"管控" |
| 特别关注 | 资深客服可能担心"经验贬值"→保留专家通道 |

#### 四、后续跟进
| 时间 | 动作 | 指标 |
|------|------|------|
| T+3天 | 各组收集反馈 | 参与意愿≥70% |
| T+7天 | SOP编写启动会 | 编写组成员确认 |
| T+14天 | 首版SOP评审 | 客服SOP完成 |
