# 分场景策略：自媒体 / 小说 / 文案

> 三场景共用 SKILL.md 的 §3–§4（诊断 + 五层爆破）。本文件只补各自重心与示例。

## 一、自媒体（公众号 / 小红书 / 短视频脚本）

**重心**：对话感、钩子前置、防情感同质化（朱雀对营销文案额外检测「情感表达同质化 / 重复话术」）。

- 钩子前置：前 100 字无概括铺垫，从具体细节 / 反问 / 惊叹切入（如「凌晨三点那些 agent 还在跑，没人盯着，想想就发毛。」）。
- 对话口吻：「你可能会问」「其实真相是」「我琢磨着」；2 处不完美停顿（「嗯……怎么说呢」）。
- 段落 2–3 行；多用「你」「你的」拉距离。
- **禁堆砌通用情绪词**：治愈/破防/绝绝子/神仙/天花板——用具体体感替代（「看完没哭，但胸口闷了一下午。」）。
- 结尾不升华、不总结，停在动作/场景/一句人话。

**示例**：
> ❌ AI 味：值得注意的是，在这个快节奏的时代，我们每个人都面临着巨大的压力。因此，学会与自己和解，显得至关重要。
> ✅ 人味：我前阵子也崩过。不是什么大事，就是有天晚上突然不想回任何消息。后来想明白了，人不是机器，喘口气不丢人。

## 二、小说 / 网文（详见 novel-rules.md）

**重心**：角色声纹区分、心理描写碎片化、作者声纹注入、番茄审核红线。

- 禁用套词见 patterns.md D 类。
- 句式长短错落：5 字 + 20 字 + 35 字随机穿插，禁连续三句同长度。
- 对话口语化：普通人省略主语、会停顿、随口吐槽；不同角色专属口头禅，杜绝千人一面。
- 心理碎片化：不用「她内心十分难过」，换指尖抠衣角、低头踢地面；加犹豫、模糊、没想明白的细碎思绪。
- 注入作者声纹：主动加角色/作者口头禅 + 故意卡壳，打破「每句工整」。
- 感官落地：冷、疼、闷、呛、发僵，不用「十分难受」。

## 三、文案（营销 / 品牌 / 带货）

**重心**：防重复话术（朱雀场景化同质化）、具体场景替代形容词、合规边界。

- 情绪钩子：紧迫感 / 好奇心 / 共情；段落 2–3 行。
- **防重复话术**：同一卖点不换三种说法硬凑；用具体场景代替形容词堆砌。
  - ❌ 省心高效、轻松管理、智能优化。
  - ✅ 半夜不用爬起来调报表，早上打开就是跑完的结果。
- 保留品牌术语与合规边界；不虚构数据、不夸大功效、不绝对化承诺。
- 产品名 / 数据用具体值，禁用「某品牌」「显著提升」「大量用户」等空泛表述。
- 标点同样遵守 banned-words.md 第三类（破折号/冒号/英文引号）。
