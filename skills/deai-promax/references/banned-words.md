# 禁用词与句式表（蒸馏合订）

> 来源：humanizer-zh-pro 24 模式 / unclecheng humanizer 4.1 / de-AI-writing 12 硬门槛 / lieflat 白名单 / jiangai 僵尸词 / fanqie 网文禁用套词。
> 用法：改写时逐类扫描，命中即按「修法」处理。括号内为典型误用与正例。

## 一、高频 AI 偏好词（朱雀词汇分布维度，密度越高越危险）

**连接/路标词（全文合计 ≤2 次）**：此外、然而、因此、与此同时、总而言之、事实上、值得注意、更关键、更要命、换句话说、首先…其次…最后、在这个过程中、在此基础上。

**讲师/讲义动作（默认删）**：拆一拆、盘一盘、捋一捋、聊一聊、划重点、敲黑板、说白了、本质上、归根结底、简单来说（无必要时不加）。

**高频分析词（禁止堆叠）**：拆解、梳理、剖析、解构、聚焦、洞察、深耕、赋能、助力、践行、驱动、构建、打造、闭环、抓手、落地、引爆、重塑。

**谄媚/协作口吻（删）**：作为 AI、截至我的知识、希望这能帮助你、接下来我们将、我们先来看、下面我们、当然！、您说得完全正确、Great question!。

**夸大意义/宣传词（删或换具体）**：至关重要、关键性的、核心的、不可或缺、深远影响、标志着、见证了、彰显了、充分体现了、举足轻重、里程碑、深远意义。

**模糊归因（删，补具体来源或删整条）**：行业报告显示、观察者指出、专家认为、研究表明、多个来源、业内人士认为、studies show、experts say。

**通用积极结尾（删，用具体动作/数据收尾）**：未来可期、前景广阔、充满希望、必将、毫无疑问、综上所述。

## 二、句式禁令

1. **「不是 A 而是 B」三毒**：假靶子（删前半句只留 B）、同义替换（A=B，合并）、无关硬凑（删了无损，直接删）。NNY 变体「不是 X。不是 Y。只是 Z。」直接删。好用法（真有人会做 A 判断且 A≠B）放行。
2. **二分对照壳**：不在于 A 而在于 B、与其 X 不如 Y、看似…实则…——多数删前半句直接说 Y；文学性反讽除外。
3. **三段式法则**：「创新、灵感与行业洞察」「高效、专注、有创造力」——改两项或四项；句内同构排比人类用得不少，只处理句间重复。
4. **戏剧化揭露**：遮羞布、面具、外衣、揭开真面目、戳穿真相——删。
5. **高频句式（合计 ≤2 次）**：一旦…就…、只有…才…、无论…都…、随着…的发展/推进、正是因为…所以…、通过…来…。
6. **二人称**：默认不用「你/你会」；确需推演最多 1 次「试想/当你」。

## 三、标点禁令（朱雀困惑度/分布维度）

- **破折号 ——**：非虚构仅在句意确有需要时保留；揭晓式破折号（「答案很简单——专注。」→「答案是专注。」）一律删；或改逗号/句号。Claude/DeepSeek 尤其高发。
- **冒号 ：**：提示语引出内容（「核心是：…」「原因有两个：…」）删提示语直写内容；空转句只宣布列表（「我见过的场景：」→「这几种场景我都见过。」）删或改写；句中正常说明性冒号、引出原话、网址代码保留。
- **英文双引号 "" ''**：改中文 «» 或「」或不加；弯引号改直引号。

## 四、网文专用禁用套词（小说场景，见 novel-rules.md 完整表）

不由得、霎时间、殊不知、良久、眼底闪过一丝波澜、此刻心中暗想、喉结滚动、周身气场、心中五味杂陈、气氛瞬间凝滞、仿佛、猛地、死死、狠狠、稳稳、紧接着（一段内重复即删到一处）、声音很平、如沐春风、梨花带雨（陈词比喻）。

## 五、推荐口语化/具体词组（缺人味时补）

- 承接词替换：然而→可/但/其实；此外→成本也得考虑；因此→所以/就；值得注意的是→这一点/这。
- 主观口语：说白了、残酷的现实是、有意思的是、我琢磨着、你猜怎么着、讲真。
- 不完美表达：嗯…怎么说呢、我就不说是谁了、我寻思了一下没寻思明白、就是单纯的、大抵、姑且、某种意义上。
- 具象替代抽象：紧张→手在抖；难过→低头踢地面；提升效率→快了多少、省了几个人；优化流程→把流程改顺了。

## 六、高频踩雷词（替换示例）

| 禁用 | 改为 |
|---|---|
| 进行/开展/实施/产生/导致 | 具体动词（催生/招致/裂变/塌缩） |
| 实现了…的提升 | 快了多少、省了几个人 |
| 完成了对…的优化 | 把…改顺了 |
| 作为/充当/拥有 | 是/有/在 |
| 显著提升/大幅增长 | 原文已有数字时提数字；无数字时恢复动词，不编 |
| 值得注意的是/值得一提的是 | 这/这一点/其实 |
