# 深度分析各章节展开指引

## 一、生意是什么？

### 1.1 业务板块拆分

目标：拆分清楚公司「靠什么赚钱」，以及各板块的规模和占比。

展示维度（尽量覆盖）：
- 按产品/业务线拆分（营收 + 毛利率）
- 按地区拆分（境内 vs 境外）
- 按客户类型拆分（如有）
- 核心指标：营收规模、同比增速、毛利率、营收占比

**证据要求**：必须基于最新财报或经研报引用的财报数据，不得估算。

---

### 1.2 历史发展时间轴

目标：让读者看出公司「从哪来，到哪去」的生命周期图。

展示格式（纯文本时间轴）：
```
{年份} ── {阶段名称} ──────────────────────────────
  • {事件描述}
  ✅ {有直接证据的关键数据}
  • 估计：{基于间接推断的描述}（注明：证据强度：弱/中等）
```

对于复合型生意的公司：
- 找出「起家生意」是什么
- 用时间轴展示每块生意的起始、扩张、成熟节奏
- 梳理生意之间的衍生逻辑（是技术迁移？是客户迁移？是品牌延伸？）

**证据要求**：时间节点若无直接年报/公告证据，必须标注「估计」。

---

### 1.3 飞轮闭环

目标：找出公司核心的正向循环机制，一旦飞轮转起来，它如何自我强化。

参考结构：
```
[起点：核心优势/产品]
        ↓
[正向传导 1：带来的结果A]
        ↓
[正向传导 2：A 如何进一步强化优势]
        ↓
[回到起点：更强的核心优势]
```

同时揭示飞轮的脆弱点：哪个环节最容易断裂？

## 二、增长潜力

### 2.1 现有生意增长分析框架

对每块生意，从以下角度分析：

| 维度 | 分析方法 |
|------|----------|
| 市场空间 | TAM 有多大？当前渗透率是多少？（需要数据支撑） |
| 增速可持续性 | 行业增速 vs 公司增速（公司是在扩份额还是只是行业 Beta？） |
| 竞争格局变化 | 竞争是在加剧还是在集中（寡头化）？ |
| 客户层面 | 客户预算、需求趋势（扩张/收缩） |

**⚠️ 严禁瞎编 TAM 数字**：若找不到第三方数据（Gartner、IDC、研报等），必须注明「证据不足，无法量化」

### 2.2 新业务生长可能性

检查：
- 公司是否在研发/试水新产品/新服务/新市场？
- 现有客户关系/技术能力/渠道是否可以迁移到新场景？
- 新业务的进展节点有没有公司披露的直接证据？

## 三、商业模式（6 个维度）

### 3.1 营销
- 获客模式（直销/经销/自然流量/品牌营销）
- 销售费用率（越低越好）
- 客户关系管理方式

### 3.2 渠道
- 销售路径（直销 vs 多级渠道）
- 渠道库存水平
- 海外/线上/线下渠道布局

### 3.3 技术
- 核心技术来源（自研 vs 集成 vs 外采）
- 研发投入（费用率 + 绝对值 + 研发人员占比）
- 技术路线（是否走多路线并行？是否与关键供应商深度绑定？）

### 3.4 供应商
- 关键物料/服务的供应商集中度
- 物料/服务替代性如何（是否有国产替代方案？）
- 供应链风险敞口（断供后的影响）

### 3.5 资本与金融
- 资本结构（有息负债率、现金储备）
- 融资历史（历次募资额 + 用途）
- 分红政策（是否持续分红？分红额 vs 募资额）
- 汇兑敞口（若大量外币收入）

### 3.6 政府业务
- 政府采购/补贴依赖程度
- 政策影响（受益还是受制）
- 监管/合规风险

## 四、竞争壁垒评估标准

**满足 4 个以上条件 = 强壁垒**

| # | 壁垒类型 | 评估要点 |
|---|----------|----------|
| 1 | 垄断 | 隐性垄断（用户自愿）优于显性垄断（用户被迫）；CSP/B2B 的认证壁垒算弱垄断 |
| 2 | 定价权 | 能不能涨价？能不能决定价值链分配？能不能创造新收费场景？ |
| 3 | 分发渠道 | 有没有现成渠道资源能低成本高效触达用户？ |
| 4 | 行为锁定 | 网络效应（用户越多越有价值）/ 上瘾性 / 品牌忠诚 |
| 5 | 成本优势 | 规模降本 / 技术降本 / 地理位置优势 |
| 6 | 客户替代能力 | 客户能不能联合起来？能不能自研替代？决策有多理性？迁移成本高不高？ |

**评估结论格式**：
```
| 壁垒条件 | 是否满足 | 证据强度 | 具体分析 |
| --- | --- | --- | --- |
| 垄断 | ❌/⚠️/✅ | 强/中/弱 | xxx |
...
总结：满足 X/6 项，[强/弱]壁垒
```

## 五、企业文化评估指引

> 与 SKILL.md「五、企业文化」7 个子项一一对应。每个子项必须给证据来源并明确「符合 / 不符合 / 证据不足」判定。

### 5.1 企业使命
- **强证据**：官网 Mission Statement / 年报「致股东信」/ 公司简介文档 / 创始人公开信
- **弱/无效**：百科、问答类二手内容

### 5.2 利润之上的追求（重点判定项）
- **事实案例口径**：碰到「能赚钱但不对」的事，看公司怎么选——选「不赚」的，才符合。
- **通过标准**：
  - ✅ 至少 **2 条**符合「利润之上追求」的事实案例；
  - ❌ 仅有 1 条、或搜不到任何事实案例 → 不符合；
  - ❌ 出现 **1 条**「为赚钱而做不对的事」的反面案例 → 直接不符合。
- **强证据**：公益/环保投入数据、员工薪酬远超行业、拒绝违规获利的具体事件报道（有日期来源）。
- **弱/无效**：官网自述口号、无对应行动的宣传语。

### 5.3 核心价值观长期是否没变
- 梳理历年（年报 / 官网 / 招股书）披露的核心价值观，逐版本列出并对比，核实是否变动、弱化或名实不符。
- **强证据**：不同年份年报/招股书中原文摘录；**弱/无效**：单一当前页面。

### 5.4 第五级经理人 + CEO 内部提拔（判定项）
- 第五级经理人 = 谦逊个性 与 坚定意志 的矛盾结合体。
- **强证据**：创始人/CEO 本人有日期出处的访谈/演讲全文；或员工、媒体、同行的具体评价（可核实）。
- **内部提拔**：查阅历任 CEO 来源（年报/公告/高管简历），确认是否由内部晋升。
- **弱/无效**：无出处的赞誉、光环标签。

### 5.5 造钟而非报时
- 设问：CEO 明天离职，公司能正常运转吗？能 → 造钟型；不能 → 报时型。
- **强证据**：治理架构、接班人机制、制度/流程沉淀、去中心化决策证据；**弱/无效**：仅靠个人英雄叙事。

### 5.6 明确的不做清单
- **强证据**：公司公开声明/文化手册/创始人访谈中明确「不做什么」（不做的业务、不赚的钱、不进的市场）；**弱/无效**：泛泛而谈。

### 5.7 稳扎稳打、基于实证的创造力
- 标准：顺逆风都稳定节奏；创新是「先射子弹、后射炮弹」的实证验证，而非豪赌。
- **强证据**：小步验证后放大投入的具体项目、逆风不慌/顺风不飘的经营记录；**弱/无效**：只有宏大愿景无落地验证。

**证据缺失的处理**：若官网/年报/研报中无法找到直接证据，必须明确写「证据不足，无法确认」，不得用「可能」「估计」来填充。

## 六、组织力评估指引

可以通过以下方式获取间接证据：

| 维度 | 获取途径 |
|------|----------|
| 目标一致性 | 年报「管理层讨论」/ 激励计划与业绩目标的绑定 |
| 人才梯度 | 年报员工情况 / LinkedIn 高管背景 / 研发人员占比 |
| 信息传递效率 | 产品迭代速度 / 对外部变化的反应速度（间接推断） |
| 决策敏捷度 | 产品 Ramp-up 速度 / 供应链决策节奏 / 组织架构 |
| 激励机制 | 股权激励计划公告（授予对象范围 + 解锁条件） |
| 自我进化 | 是否有「复盘文化」/ 高管是否公开讨论战略调整 |

**注意**：组织力信息最难获取，绝大多数情况下证据不足。若职友集/看准网/脉脉抓取失败，必须标注，不得瞎写。

## 七、管理层再投资（资本配置能力）

> 与 SKILL.md「七、管理层再投资」一一对应。核心检验「优秀生意是否遇到优秀资本配置者」：再投资回报是否达标 + 并购/回购/分红行为是否体现纪律与理性。所有结论须附证据来源，证据不足项标注「⚠️ 证据不足」。

### 7.1 数据层面（量化再投资回报效率）

#### 7.1.1 增量 ROIC（5Y / 3Y / 1Y）
- **公式**：增量 ROIC = ΔNOPAT / ΔIC。无 NOPAT 时用「Δ净利润 / Δ（有息负债 + 股东权益）」近似并注口径。
- **数据来源**：neodata 逐年拉取 NOPAT（或净利润）与投入资本（IC = 有息负债 + 股东权益），自行计算相邻期差值。
- **判定**：增量 ROIC ≥ 存量 ROIC（板块四均值）→ 创造价值；显著低于 → 边际递减，警惕资本囤积。

#### 7.1.2 平均留存收益回报率 RORE（5Y / 3Y / 1Y）
- **公式**：RORE = 净利润 / 平均留存收益；保守口径 = 期间累计净利润 / 期间累计留存收益。留存收益 = 未分配利润期初期末净增额（净利润 − 分红）。
- **判定**：RORE ≥ 长期 ROIC/ROE 均值 → 留存合理；长期低于 → 减分（不如分给股东）。

#### 7.1.3 可持续增长率 g = 再投资率 × ROIC（5Y / 3Y / 1Y）
- **公式**：再投资率 = 留存收益 / 净利润 = 1 − 分红率。
- **用途**：g 与实际营收/利润增速对比。g ≫ 实际增速 → 再投资过度转低效资产；实际增速 ≫ g → 增长靠杠杆/并购，回 7.2 核查资本来源。

#### 7.1.4 10 年资本配置综合回报
- **公式**：（期末市值 − 期初市值）/ 期间累计留存收益。
- **口径**：期初/期末市值取「10 年前」与「当前」总市值；累计留存收益 = 10 年净利润之和 − 10 年累计分红（来源：westock-data dividend + 年报利润表）。
- **判定**：> 1 → 留存创造增值；< 1（或为负）→ 长期损毁价值，资本配置失败核心信号。

**呈现建议**：4 个指标各做一张三档窗口（5Y/3Y/1Y）表格，附数据来源与计算口径说明。

### 7.2 行为层面（并购 / 回购 / 分红的纪律与理性）

#### 7.2.1 并购
| 检查项 | 获取途径 | 加分 / 减分 |
|--------|----------|-------------|
| 并购频率 | 公告 `westock-data news <code> --type 0`、年报重大资产购买章节 | 少而精 +；高频高溢价 − |
| 商誉/总资产 | 各期末商誉余额 ÷ 总资产，看趋势 | 占比低 +；高悬 − |
| 商誉减值 | 年报资产减值章节、公告，列年份/金额/原因 | 无减值 +；反复减值 −（区分洗大澡 vs 碎片化） |

#### 7.2.2 回购
| 检查项 | 获取途径 | 加分 / 减分 |
|--------|----------|-------------|
| 回购政策 | 回购预案/实施公告（计划、触发条件、金额区间） | 常态化 + |
| 注销与否 | 回购后流通股是否注销 | 注销 +；转激励/转债库存股 中性偏减分 |
| 价位与资金来源 | 回购均价区间 vs 股价历史分位；资金来源（自有/举债） | 低位+自有 +；高位+举债 − |

#### 7.2.3 分红
| 检查项 | 获取途径 | 加分 / 减分 |
|--------|----------|-------------|
| 分红政策 | 分红历史 `westock-data dividend`、年报分红章节 | 制度化/承诺化 + |
| 稳定性 | 近 10 年分红连续性、分红率趋势 | 连续且有序提升 + |
| 阶段匹配 | 对比生命周期 | 成长期低分红高再投(回报率高) 合理；成熟期高分红 纪律 +；成熟期低分红无可投机会 − |

**注意**：行为层证据多来自公告与年报原文，需引用具体公告日期/章节；数据层与行为层冲突（如数据好但行为激进）时，必须明确指出并提示风险。

**证据缺失处理**：无法取得 NOPAT/IC/商誉明细时标注「⚠️ 证据不足」，不得估算填充。
