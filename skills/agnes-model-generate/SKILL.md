# Agnes AI 模型自动生成技能

## 是什么

一个面向创作者的智能生成技能，帮你自动调用 **Agnes AI 免费模型**完成视觉与内容创作。你只需要说「我要做什么」，剩下的技术细节全部自动处理。

## 核心能力

| 场景 | 调用什么模型 | 自动任务 |
|------|-------------|----------|
| 海报生成 | `agnes-3.0-flash` + `agnes-image-2.5-flash` | 自动生成标题/副标/卖点/CTA + 生底图 + 本地排版 |
| 朋友圈/小红书配图 | `agnes-image-2.5-flash` | 自动推荐尺寸、无水印高清输出 |
| 短视频首帧/动态预览 | `agnes-video-2.5-flash` | 自动生成 5 秒 720P 视频（限时免费） |
| 营销文案创作 | `agnes-3.0-flash` | 自动生成主题、结构、金句 |

## 侧重点：纯用户交互，零技术门槛
本技能对外暴露简洁的对话式接口，内部调用 `agnes-ai-free` 技能的完整能力，不要求用户掌握 Prompt 工程、API、排版等技术细节。

## 技术实现

本技能**不重复实现**，而是**调度** `agnes-ai-free` 技能的能力，通过以下方式封装：

### 1. 调用文案生成
```python
from agnes_client import AgnesClient
client = AgnesClient()
copy = client.generate_poster_copy(
    theme=用户需求,
    style=根据关键词自动选择 ({美业/节庆/极简}),
    brand=用户提供或默认"官方",
    product=用户提供或默认"",
    extra_context=用户提供或默认""
)
```

### 2. 调用图像生成
```python
img_bytes = client.generate_image(
    prompt=copy["image_prompt"],  # 文案里自动生成的英文 prompt
    size="2K",
    ratio="9:16"
)
```

### 3. 调用排版合成
```python
output_path = generate_poster_with_playwright(
    html_template=美业/节庆/极简模板,
    base_image=img_bytes,
    copy_data=copy
)
```

### 4. 交付结果
```python
present_files([output_path])  # 或直接把文件内容返回给用户
```

## 用户输入处理

### 场景 1：仅主题，无风格
**用户**：「生成一张情人节促销海报」
**你**：检测到「情人节」→ 推荐节日风格，询问品牌名或直接用「官方」

### 场景 2：指定风格
**用户**：「我做得很现代简约的产品海报，帮我生成一张」
**你**：识别到「现代简约」→ 使用 `minimal` 模板，生成 aigns-3.0-flash 文案与 agnes-image-2.5-flash 图像

### 场景 3：补充信息
**用户**：「生成一张新品发布海报，品牌是 abc，主打成分 x，适合敏感肌」
**你**：整合 `theme`="新品发布"、`brand`="abc"、`product`="x"、`extra`="适合敏感肌"，调用 `agnes-3.0-flash` 生成专业美业文案

### 场景 4：短视频
**用户**：「生成视频首帧，内容是 [...]」
**你**：调用 `agnes-video-2.5-flash`，自动推荐 5 秒 + 720P + 9:16（适合短视频封面）

## 交付物格式

### 海报类
- 1080×1920 @ 2x（视网膜级，手机海报 Common 文件大小约 800 KB - 1.5 MB）
- 文件名：`poster_{主题}_{风格}_{时间戳}.jpg`
- 通过 `present_files` 一次性展示

### 短视频类
- 文件名：`video_{内容}_{时间戳}.mp4`
- 尺寸：720p（1280x720）或根据提供的需求自动调整
- 时长：5-10 秒（推荐 5 秒快速预览）

### 文案类
- 直接返回结构化 JSON：`{ title, subtitle, slogan, selling_points, cta, contact }`
- 或输出纯文本，方便用户复制

## 注意事项

1. **隐私与版权**：用户输入的核心信息（品牌名、产品、具体文案）需存入输出随机时间戳文件，不持久化留存
2. **生成时间**：海报类任务约 1-2 分钟（文案 5-10s + 图像 10-30s + 排版 10-20s）
3. **模型费用**：完全免费（agnes-3.0-flash / agnes-image-2.5-flash / agnes-video-2.5-flash 均有天使用户体验价 $0）
4. **质量控制**：如果某步骤失败，自动降级或重试（重试 3 次，指数退避），仍失败则告知用户并建议手动调整提示词
