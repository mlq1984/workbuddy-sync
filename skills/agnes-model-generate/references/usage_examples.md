# Agnes AI 模型自动生成技能 - 使用示例库

## 核心理念

**零技术门槛，一句话生成创意内容。**

本技能面向视觉创作者、营销人员，封装 agnes-ai-free 技能的所有能力，提供自然的对话式交互。你不需要懂 Prompt 工程、API、排版，只需要说「我要做什么」。

---

## 场景 1：春节海报生成

### 用户输入
> "生成一张春节促销海报"

### 处理流程
1. 识别关键词「春节」→ 推荐节日风格（festival）
2. 自动生成文案（agnes-3.0-flash）
3. 自动生成底图（agnes-image-2.5-flash，2K 9:16，无水印）
4. 自动排版合成（HTML 模板 + Playwright → 1080×1920 JPG）

### 预期输出文案
```json
{
  "title": "新春大促 · 好礼不停",
  "subtitle": "农历新年 全场 8 折起",
  "slogan": "欢度春节，焕新启程",
  "selling_points": [
    {"main": "全场 8 折", "sub": "新年专属折扣"},
    {"main": "赠加湿器", "sub": "购满 299 即送"},
    {"main": "免费配送", "sub": "春节不打烊"}
  ],
  "cta": "领取福利",
  "contact": "www.brand.com | 400-xxx-xxxx",
  "image_prompt": "Chinese New Year celebration poster, red paper cut style, golden lanterns and firecrackers, festive atmosphere, cinematic lighting, symmetrical composition, 8k quality, no text"
}
```

### 最终交付
一張 1080×1920 的高清 JPG 海报，可直接发朋友圈/公众号/小红书。

## 场景 2：护肤品海报生成

### 用户输入
> "我有一个补水面膜的信息：品牌是 abc，主打成分是玻尿酸，适合敏感肌，帮我生成一张海报"

### 处理流程
1. 识别关键词「护肤品/面膜」→ 推荐美业风格（beauty）
2. 整合所有信息：`theme="补水面膜"` / `brand="abc"` / `product="玻尿酸"` / `extra="适合敏感肌"`
3. 自动生成专业文案（美业模板）
4. 自动生成护理实景风格底图（皮肤科学感）
5. 自动排版（左文右图、临床感）

### 预期文案（精简版）
- Title：「胶原补水锦囊」
- Selling Points：
  - 玻尿酸深渗补水 → 24h 水润持绩
  - 敏感肌友好 → 低敏配方安心
  - 3 分钟速达 → 晨间快速唤醒

## 场景 4：短视频首帧生成

### 用户输入
> "帮我生成一个短视频首帧，内容是：站在海边，黄昏时分，海浪拍打沙滩，远处有一艘小船"

### 处理流程
1. 识别为短视频需求 → 使用 agnes-video-2.5-flash
2. 自动推荐 5 秒 720P + 9:16（适合短视频封面）
3. 生成本帧图像
4. 交付 1080×1920 JPG（可直接用作封面）

### 轮询等待
视频生成是异步任务，内部自动轮询（最多 2 分钟），直到 `status=completed`，取视频 URL 下载。

```

📁 输出文件：poster_output/poster_{风格}_{时间戳}.jpg
📐 规格：1080×1920 @2x（视网膜级，适合手机海报）

你是要查看图片，还是需要调整风格/文案？
```

## 降级策略

| 失败环节 | 降级方案 |
|----------|----------|
| 文案生成失败（agnes-3.0-flash） | 使用内置默认文案模板 |
| 图像生成失败（agnes-image-2.5-flash） | 降低分辨率到 1K，或回退智谱免费档 |
| 排版失败 | 直接输出底图（1472×2624）+ 文案文本，不排版 |
| 短视频生成失败 | 降级生成本帧图片，告知用户视频生成较慢 |

## 用户常见问题

**Q: 生成海报需要多久？**
A: 整体流程约 1-2 分钟（文案 5-10s + 图像 10-30s + 排版 10-20s）。

**Q: 生成费用是多少？**
A: 完全免费。Agnes AI 免费模型（agnes-3.0-flash / agnes-image-2.5-flash / agnes-video-2.5-flash）目前天使用户体验价全部 $0。

**Q: 可以指定尺寸吗？**
A: 自动推荐 2K 9:16（1472×2624），适合手机海报。如需其他尺寸，用户可以直接说「横版海报」或「海报背景」，内部会自动调整 ratio 参数。

**Q: 可以修改生成的内容吗？**
A: 可以。用户说「把标题改一下」「文案太长」「卖点减少一条」，重新生成即可。

**Q: 生成的海报可以商用吗？**
A: 输出文件为用户私有，完全可商用。

**Q: 可以一次生成多张吗？**
A: 当前版本每次只生成 1 张。如需多张，用户可以说「给我 3 张不同风格的」，内部会循环生成 1 次，请求用户确认后再生成下一张。
